# 个人中心

个人中心汇聚与当前登录账号相关的自助设置：个人信息、修改密码、APIKEY、我的通知、个人默认模型与本地 runner 配置。入口位于顶栏右侧个人菜单。

## 个人信息

路径：`/personal`。展示头像（姓名首字母色块）与账号资料表单。

| 字段 | 可编辑 | 说明                         |
| ---- | ------ | ---------------------------- |
| 头像 | 否     | 系统按姓名首字母自动生成色块 |
| 邮箱 | 否     | 即登录名，不可修改           |
| 姓名 | 是     | 显示名称                     |
| 电话 | 是     | 联系电话                     |

操作：修改姓名/电话后点击保存，成功后顶栏与页面即时刷新。

## 修改密码

路径：`/personal/password`。输入当前密码与新密码完成修改；密码以 argon2 哈希存储，修改成功后使用新密码重新登录。

## APIKEY 管理

路径：`/personal/api-keys`。APIKEY（AK/SK）供 CI 流水线、脚本等外部程序调用平台 OpenAPI（契约 `/api/v1`）。

操作流程：

1. 点击「新建 APIKEY」，生成 AccessKey 与 SecretKey；
2. **SecretKey 仅在创建时展示一次**，请立即复制并妥善保管，关闭弹窗后无法再次查看；
3. 外部调用时以 AK/SK 完成认证；
4. 不再使用时在列表中吊销（删除）对应 Key。

| 项        | 说明                                |
| --------- | ----------------------------------- |
| 数量上限  | 每账号最多 5 把，超出需先吊销再新建 |
| SK 可见性 | 仅创建时一次展示，之后不可查询      |
| 吊销      | 列表操作，立即生效                  |

!> SecretKey 丢失只能吊销旧 Key 并重新创建，平台无法找回。

## 我的通知

路径：`/personal/notifications`。集中查看本账号收到的全部站内通知。

- 仅展示近 90 天的通知；
- 支持「仅未读」筛选、单条标记已读、全部标记已读；
- 通知来源包括事件通知与关注对象变更，事件目录见 [消息管理](manual/project/message.md)。

顶栏通知铃铛是轻量入口：每 30 秒轮询未读数并显示徽标；点开显示最近 10 条通知，打开面板即视为已查看并自动标记全部已读。

通知列表项字段：

| 字段     | 说明                                 |
| -------- | ------------------------------------ |
| 类型     | 触发事件（如缺陷创建、计划执行完成） |
| 标题     | 事件标题                             |
| 内容     | 事件摘要（含操作人、对象等）         |
| 已读状态 | 未读高亮；已读显示阅读时间           |
| 时间     | 通知产生时间                         |

## 个人默认模型

路径：`/personal/ai-model`。当系统配置了多个 AI 模型时，可在此绑定个人默认模型，AI 生成与智能助手默认使用该模型。系统模型由管理员在「系统 › 模型设置」统一配置，见 [AI 能力](manual/ai.md)。

## 本地 Runner

路径：`/personal/local-runner`。用于本机直连执行场景的配置页：

| 项               | 说明                                                   |
| ---------------- | ------------------------------------------------------ |
| 本地 runner 地址 | 仅允许环回地址（loopback），如 `http://127.0.0.1:xxxx` |
| 连通检测         | 一键检测地址可达性，展示检测结果与失败详情             |
| 优先本地开关     | 开启后符合条件的执行优先走本地 runner                  |

?> 地址仅限环回地址是安全边界，防止将执行流量指向他人机器。检测失败时请先确认本地 runner 进程已启动。

## 边界与注意事项

- 个人电话为选填信息，仅用于展示与通讯录场景。
- APIKEY 与密码属于账号凭证：AK/SK 泄露请立即吊销；密码请使用足够强度的组合。
- 我的通知仅保留近 90 天，更早的通知可在系统日志（管理员）中追溯审计记录，见 [用户管理](manual/system/users.md)。
