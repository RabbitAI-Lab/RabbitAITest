# 通用功能

登录 RabbitAITest 后即进入控制台。本页介绍所有功能模块共用的基础能力：控制台布局、组织与项目切换、权限与模块开关概念，以及左侧导航的双重门控规则。

## 控制台布局

控制台由顶栏、左侧导航与内容区三部分组成：

| 区域     | 组成                                                                                                                                       | 说明                                             |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------ |
| 顶栏     | 品牌、组织切换器、项目切换器、AI 助手入口（Sparkles 图标）、通知铃铛（未读徽标）、个人菜单                                                  | 全局入口；组织/项目切换影响左侧导航与数据范围     |
| 左侧导航 | 工作台、测试跟踪（用例/评审/计划/缺陷）、接口测试（调试/定义/场景/报告/Mock）、文件管理、任务中心等                                          | 按「权限点 ∧ 项目模块开关」双门控动态渲染         |
| 内容区   | 当前功能页面                                                                                                                               | 项目级页面均作用于当前选中的项目                 |

?> 顶栏个人菜单可进入个人中心（个人信息、密码、APIKEY、我的通知、个人默认模型、本地 runner）与退出登录，见 [个人中心](manual/common/profile.md)。

## 组织与项目切换

RabbitAITest 的资源层级为「组织 → 项目 → 模块」：

- **组织切换器**：切换当前组织。切换后，组织级页面（项目管理、成员管理、部门管理、用户组、模板管理）与组织内项目列表随之刷新。
- **项目切换器**：切换当前项目。测试用例、接口测试、环境、文件、公共脚本等所有项目级数据均以当前项目为上下文。

系统初始化（`pnpm db:seed`）后自动创建：

| 层级 | 初始数据                                   |
| ---- | ------------------------------------------ |
| 组织 | 管理员组织                                 |
| 项目 | 管理项目                                   |
| 模块 | 未规划用例 / 未规划接口 / 未规划场景（三个默认模块） |

默认管理员账号为 `admin@rabbit.test`（初始密码 `rabbit-admin-123`，可用环境变量 `RABBIT_SEED_ADMIN_PASSWORD` 覆盖），该账号同时属于系统管理员（system 级）、组织管理员与项目管理员用户组。

## 权限模型

访问控制基于权限点（Permission Point）与用户组：

- **权限点格式**：`{SCOPE}_{RESOURCE}:{ACTION}`，ACTION 取值 READ / CREATE / UPDATE / DELETE（个别资源扩展 SHARE / EXPORT），系统共 109 个权限点。
- **用户组**：用户可属于多个组；最终权限 = 各组权限并集 − 禁用（deny）交集，deny 按资源前缀整组剔除。
- **端点声明**：每个 API 端点经 `withPermission()` 声明所需权限点，未满足即返回 403。
- **预置用户组**（六组，`isSystem` 组只读不可删）：系统管理员、系统成员、组织管理员、组织成员、项目管理员、项目成员。

?> 常见权限点示例：项目管理员/项目成员（PROJECT_MEMBER）含用例读写、评审、计划读改、缺陷读写、接口/环境/文件/脚本创建等；系统级页面分别要求 `SYSTEM_USER:*`、`SYSTEM_PARAM:*`、`SYSTEM_POOL:*`、`SYSTEM_PLUGIN:*`、`SYSTEM_AI:*` 等权限点。

## 模块开关与导航门控

每个项目可独立开启/关闭功能模块（项目 › 设置 › 基本信息，见 [项目与模板](manual/project/overview.md)）：

| 模块开关 | 名称     | 说明                                                       |
| -------- | -------- | ---------------------------------------------------------- |
| case     | 测试用例 | 用例库、评审与回收站（默认开启）                            |
| plan     | 测试计划 | 计划编排与执行（默认开启）                                  |
| bug      | 缺陷管理 | 缺陷提交与流转（默认开启）                                  |
| api      | 接口测试 | 接口调试与定义（默认开启）                                  |
| load     | 性能测试 | 企业版方向占位入口，无执行能力（默认关闭）                  |
| uit      | UI 测试  | 企业版方向占位入口，无执行能力（默认关闭）                  |

左侧导航的渲染规则为双门控：**菜单项 = 当前用户拥有对应权限点 ∧ 当前项目已开启对应模块开关**。任一条件不满足，菜单不出现；直接访问未授权路由同样会被服务端权限校验拦截。

## 常用路径速查

| 功能域   | 路径                                        | 说明                 |
| -------- | ------------------------------------------- | -------------------- |
| 工作台   | `/`                                          | 项目概览与统计       |
| 测试跟踪 | `/cases`、`/reviews`、`/plans`、`/bugs`       | 用例/评审/计划/缺陷  |

| 组织级   | `/org/projects`、`/org/members` 等           | 组织管理入口集       |
| 项目设置 | `/settings/*`                                | 信息/成员/环境等     |
| 系统设置 | `/system/*`                                  | 用户/参数/池等       |
| 个人中心 | `/personal/*`                                | 个人自助设置         |

## 边界与注意事项

- 组织切换器与项目切换器是全局上下文：任何页面操作前先确认当前所在组织/项目，避免数据写入错误项目。
- load / uit 模块开关属于企业版方向占位，社区版开启后仅出现导航占位入口，无实际执行能力。
- 无权限的菜单不出现是设计行为（不是缺陷）；如需访问某功能，请联系管理员调整用户组或权限。
- 社区版默认单组织运行；多组织管理（`/system/orgs`）为 License 门控的企业版能力，见 [认证与授权（企业版）](manual/system/enterprise.md)。
