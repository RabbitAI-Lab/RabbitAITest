# 参数设置

参数设置集中管理平台级运行参数，共五组：基础、SMTP 邮件、文件、数据清理与主题品牌。参数修改后对全平台生效。

> 所需权限：SYSTEM_PARAM:READ / SYSTEM_PARAM:UPDATE

## 概念

路径：`/system/params`（系统 › 参数设置）。参数以组为单位分区展示，编辑后保存即生效。系统初始化即预置四组参数（base / smtp / file / cleanup），theme 组用于主题品牌定制。

## 参数组一览

| 组      | 用途           | 关键参数                                                                 |
| ------- | -------------- | ------------------------------------------------------------------------ |
| base    | 基础配置       | siteUrl（站点地址，默认 `http://localhost:3000`）、loginBanner（登录横幅） |
| smtp    | 邮件发送       | SMTP 服务器、端口（默认 465/SSL）、账号密码等；初始为空配置              |
| file    | 文件上传       | maxSizeMb（单文件大小上限，默认 50MB）                                    |
| cleanup | 数据清理       | 日志保留天数（默认 90 天）                                                |
| theme   | 主题品牌       | 品牌名、Logo 等（dataUrl 图片，见下方边界）                               |

## 各组参数明细

### base（基础配置）

| 参数        | 默认值                   | 说明                         |
| ----------- | ------------------------ | ---------------------------- |
| siteUrl     | `http://localhost:3000`  | 站点对外地址                 |
| loginBanner | 空                       | 登录页横幅文案               |

### smtp（邮件发送）

| 参数   | 默认值 | 说明                       |
| ------ | ------ | -------------------------- |
| host   | 空     | SMTP 服务器地址            |
| port   | 465    | SMTP 端口                  |
| ssl    | true   | 是否 SSL 加密连接          |
| user   | 空     | 发信账号                   |
| pass   | 空     | 发信密码（界面以 ****** 掩码，编辑留空=不改） |
| from   | 空     | 发件人地址                 |

### file（文件上传）

| 参数      | 默认值 | 说明                     |
| --------- | ------ | ------------------------ |
| maxSizeMb | 50     | 单文件大小上限（MB）     |

### cleanup（数据清理）

| 参数                  | 默认值 | 说明                             |
| --------------------- | ------ | -------------------------------- |
| logRetentionDays      | 90     | 日志保留天数                     |
| changeLogRetentionDays | 90    | 变更记录保留天数                 |

## 操作流程

1. 进入 系统 › 参数设置，选择参数组；
2. 修改参数值后保存；
3. SMTP 组提供**测试连接**：填写完毕后发送测试邮件验证配置正确性。

各参数影响的范围：

- **siteUrl**：用于消息中的链接拼接等对外地址场景，部署在非默认域名/端口时务必修改；
- **SMTP**：邮件渠道机器人（见[消息管理](manual/project/message.md)）依赖此组配置，未配置时邮件通知发送失败；
- **maxSizeMb**：文件管理上传、缺陷附件等统一读取该上限（见[文件管理](manual/project/file.md)）；
- **日志保留天数**：到期数据按计划清理，同时约束站内通知与审计日志的可见周期；
- **theme**：定制平台品牌展示。

## 边界与注意事项

- theme 组中 dataUrl 图片二进制上限 200KB（按 base64 解码后计），超出需先压缩。
- SMTP 凭据与 base64 图片等敏感内容保存后不在界面回显，编辑留空表示保持原值。
- 修改日志保留天数对已产生的数据按新周期执行，缩短周期会提前清理旧数据，请谨慎评估。
- 参数为系统级：立即影响所有组织与项目，建议变更前确认影响面。
