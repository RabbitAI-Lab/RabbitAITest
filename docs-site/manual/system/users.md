# 用户管理

用户管理是平台管理员的系统级工作台：管理全平台用户账号、系统级用户组，并通过三级审计日志追溯系统/组织/项目的敏感操作。

> 所需权限：SYSTEM_USER:READ / SYSTEM_USER:CREATE / SYSTEM_USER:UPDATE / SYSTEM_USER:DELETE

## 用户管理

路径：`/system/users`（系统 › 用户管理）。

- **容量进度条**：页面顶部展示当前用户数与上限。社区版默认上限 **30 人**；接近上限时提示扩容（企业版授权后不限额或按授权上限显示）。
- 管理员在此创建用户、编辑资料、启用/停用与删除账号。

操作流程（创建用户）：

1. 进入 系统 › 用户管理，点击「新建用户」；
2. 填写邮箱（登录名）、姓名与初始密码；
3. 保存后将用户加入相应**用户组**获得权限（见下节）。

用户列表与操作：

| 操作     | 说明                                           |
| -------- | ---------------------------------------------- |
| 编辑     | 修改姓名、电话等资料                           |
| 启用/停用 | 停用后无法登录，数据保留                       |
| 删除     | 移除账号（建议先转移其负责的资源）             |
| 加入用户组 | 在用户组管理中把用户加入一个或多个组         |

列表顶部标题实时显示当前口径：社区版为「系统用户（上限 30 人 · 社区版）」，企业版按授权显示「授权上限不限」或具体上限。

!> 社区版用户数达到 30 上限后无法继续创建/注册新用户；企业版可通过 USER_SCALE 授权扩容，见[认证与授权（企业版）](manual/system/enterprise.md)。

## 用户组

路径：`/system/groups`（系统 › 用户组）。系统级用户组跨组织生效，预置六组：

| 用户组     | 范围   | 说明                                                       |
| ---------- | ------ | ---------------------------------------------------------- |
| 系统管理员 | system | 全平台管理权限（isSystem 只读组）                          |
| 系统成员   | system | 基础登录与个人中心权限（isSystem 只读组）                  |
| 组织管理员 | org    | 组织级管理（项目/成员/模板等）                             |
| 组织成员   | org    | 组织基础权限                                               |
| 项目管理员 | project | 项目内全面管理                                             |
| 项目成员   | project | 日常测试权限：用例读写、评审、计划读改、缺陷读写、接口/环境/文件/脚本创建等 |

权限合并规则：用户最终权限 = 所属各组权限**并集 − 禁用交集**（deny 按资源前缀整组剔除）。组织级/项目级用户组分别在 `/org/groups` 与 `/settings/groups` 维护（见[项目与模板](manual/project/overview.md)）。

## 系统日志（三级审计）

路径：`/system/audit-logs`（系统 › 系统日志）。审计日志按三级范围记录：

| 级别 | 记录内容                           |
| ---- | ---------------------------------- |
| 系统 | 用户/参数/资源池/插件/License 等系统级变更 |
| 组织 | 组织成员、模板、集成等组织级变更   |
| 项目 | 项目内关键操作                     |

日志保留时长由系统参数 cleanup 组控制（默认 90 天），见[参数设置](manual/system/params.md)。排障时按级别+关键字检索操作记录，可定位「谁在何时改了什么」。

## 登录与注册

| 入口       | 说明                                                                 |
| ---------- | -------------------------------------------------------------------- |
| `/login`   | 账号密码登录；系统配置 LDAP 后出现「账号登录 / LDAP 目录登录」双 Tab  |
| 更多登录方式 | SSO（OIDC / OAuth2 / CAS）与扫码登录（企业微信/钉钉/飞书）——企业版门控 |
| `/register`| 用户自注册（同样受用户容量上限约束）                                 |

?> 自注册与管理员创建共用容量判定：达到上限时注册入口同样拒绝创建，提示用户上限。

## 边界与注意事项

- isSystem 预置组（系统管理员/系统成员等）只读，不可删除；自定义组建议从最接近的预置组复制后再裁剪。
- 删除用户前请先处理其负责的资源（用例、计划、缺陷处理人等），避免悬空引用。
- 审计日志仅记录敏感操作与变更，不替代业务数据的历史版本。
