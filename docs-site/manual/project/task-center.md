# 任务中心

任务中心汇聚所有异步执行任务：接口调试、接口用例、场景与计划执行产生的任务在此统一查看、跟踪与停止，并支持定时任务管理。

<img src="_media/shots/tasks.png" alt="任务中心">

## 概念

路径：`/tasks`（任务中心）。页面提供两级视图：

- **范围 Tabs**：本项目 / 全部项目——切换任务列表的数据范围；
- **子 Tabs**：实时任务（列表动态轮询刷新）/ 定时任务（场景定时执行配置）。

任务中心与报告中心互补：任务中心关注执行过程与状态，报告中心（`/reports`）沉淀执行结果与统计分析。

## 任务类型

| 类型       | 标签     | 来源                                   |
| ---------- | -------- | -------------------------------------- |
| api_debug  | 接口调试 | 接口调试页发起的调试执行                |
| api_case   | 接口用例 | 接口用例（单条/批量）执行               |
| scenario   | 场景     | 场景执行（手动或定时）                  |
| plan       | 计划     | 测试计划执行                            |

## 任务状态

| 状态      | 含义                             |
| --------- | -------------------------------- |
| PENDING   | 已入队等待执行                   |
| RUNNING   | 执行中                           |
| SUCCESS   | 执行成功                         |
| FAILED    | 执行失败                         |
| STOPPED   | 被手动停止                       |

## 操作流程

1. 顶部选择范围（本项目/全部项目）与子 Tab（实时任务/定时任务）；
2. 在任务列表查看各任务的类型、状态、耗时与触发信息（实时任务列表自动轮询刷新）；
3. 点击任务进入对应**执行报告**（`/reports/{taskId}`）查看统计、步骤与日志详情，见[测试报告](manual/api/report.md)；
4. 对 RUNNING/PENDING 状态的任务可点击「停止」，任务转入 STOPPED。

?> 定时任务（cron）基于场景定时执行配置产生，任务启用/停用事件会触发消息通知，见[消息管理](manual/project/message.md)。

## 列表字段

| 字段   | 说明                                                       |
| ------ | ---------------------------------------------------------- |
| 类型   | 接口调试 / 接口用例 / 场景 / 计划（彩色标签区分）           |
| 名称   | 任务/执行对象名称                                          |
| 状态   | PENDING / RUNNING / SUCCESS / FAILED / STOPPED             |
| 耗时   | 人性化展示：842ms / 1.2s / 45s / 3min / 1.5h               |
| 触发人 | 发起执行的用户                                             |
| 时间   | 任务创建/完成时间                                          |
| 操作   | 查看报告、停止                                             |
| 项目   | 「全部项目」范围下显示任务所属项目                         |

## 定时任务

定时任务子 Tab 管理基于 cron 的场景定时执行：

- 在场景的定时配置中登记执行计划（cron 表达式）后，任务按计划自动产生并执行；
- 定时任务的启用与停用会分别触发 SCHEDULE_ENABLED / SCHEDULE_DISABLED 事件通知；
- 历史产生的执行记录与实时任务一样可在列表与报告中追溯；
- 无定时任务时页面显示空态提示，引导前往场景配置定时。

?> 定时场景执行完成同样会触发 SCENARIO_EXEC_COMPLETED 事件通知（手动/定时共用同一事件），可在消息管理中配置接收。

## 边界与注意事项

- 「全部项目」范围下任务量较大时建议结合状态/类型筛选定位。
- 实时任务列表为动态轮询，非实时推送；列表刷新间隔内状态可能短暂滞后。
- 停止任务对已完成的步骤不回滚，报告保留已执行部分的结果。
- 任务执行依赖资源池（默认资源池），池不可用或并发占满时任务停留在 PENDING，见 [资源池](manual/system/pools.md)。
