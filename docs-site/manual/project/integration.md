# 服务集成与同步

服务集成实现 RabbitAITest 与三方平台的打通：对接 Jira / 禅道 / TAPD 实现缺陷双向同步；对接 Swagger/OpenAPI 文档源实现接口定义定时同步。

## 概念

- **缺陷双向同步**：平台内缺陷与三方平台工单双向映射——平台内新建/流转缺陷同步到三方；三方侧状态变化回写平台。
- **平台适配器**：平台交互（API 调用、字段映射）由 `plugins/` 目录下的平台插件适配器完成（jira-platform / zentao-platform / tapd-platform），经 plugin-runner 线程隔离执行。
- **凭据安全**：三方平台凭据加密存储、不回显；再次编辑时留空表示不修改。

| 支持平台 | 适配器插件       | 同步对象 |
| -------- | ---------------- | -------- |
| Jira     | jira-platform    | 缺陷工单 |
| 禅道     | zentao-platform  | 缺陷（Bug） |
| TAPD     | tapd-platform    | 缺陷    |

## 缺陷平台对接

路径：`/settings/integrations`（项目 › 设置 › 服务集成，组织级对接配置）。

操作流程：

1. 进入 项目 › 设置 › 服务集成，点击新建对接；
2. 选择平台（Jira / 禅道 / TAPD），填写服务地址与凭据（如 Jira 的 `https://jira.example.com` 与账号凭据）；
3. 配置**缺陷类型映射**：把平台缺陷类型映射到三方平台类型。默认映射示例：

   | 平台内类型 | Jira   | 禅道        |
   | ---------- | ------ | ----------- |
   | 功能缺陷   | Bug    | codeerror   |

4. 保存并启用后，缺陷的双向同步按映射自动进行。

对接配置要点：

| 配置项   | 说明                                                       |
| -------- | ---------------------------------------------------------- |
| 平台     | jira / zentao / tapd 三选一（默认 jira）                   |
| 服务地址 | 三方平台 API 地址                                          |
| 凭据     | 账号/令牌等，加密存储、不回显                               |
| 缺陷类型映射 | 平台内缺陷类型 ↔ 三方平台工单类型（可多组）             |

!> 对接配置中的凭据仅写入时可见，列表与编辑界面均不回显；修改凭据请重新输入，留空则保持原值。

## Swagger 定时同步

路径：`/settings/swagger-sync`（项目 › 设置 › Swagger 同步）。

将 Swagger/OpenAPI 文档 URL 登记为同步任务，按计划定时拉取并更新接口定义：

1. 点击新建任务，填写 Swagger 文档 URL 与同步计划；
2. 任务列表支持：编辑（任务 CRUD）、**立即同步**（手动触发一次拉取）、查看**同步历史**（每次同步的结果记录）；
3. 同步成功后，新增/变更的接口出现在接口定义列表中，见[接口定义](manual/api/definition.md)。

同步任务字段：

| 字段     | 说明                                   |
| -------- | -------------------------------------- |
| 文档 URL | Swagger/OpenAPI 文档地址               |
| 同步计划 | 定时拉取的周期配置                     |
| 状态     | 任务启用/停用                          |
| 同步历史 | 每次同步的时间与结果（成功/失败及原因）|

## 双向同步行为

- **平台 → 三方**：平台内新建缺陷、流转状态、补充评论时，按映射在三方平台创建/更新工单；
- **三方 → 平台**：三方平台侧的工单状态变化回写平台缺陷，保持两侧状态一致；
- 同步经对应平台插件适配器（plugin-runner 隔离执行）完成，单次同步失败不影响缺陷本地数据。

## 边界与注意事项

- 三方平台对接为**组织级**配置，同一组织内项目共用；请确认凭据账号在三方平台有工单读写权限。
- 双向同步依赖对应平台插件处于启用状态（系统 › 插件管理，见 [插件管理](manual/system/plugins.md)）；插件停用后同步中断，恢复启用后继续。
- Swagger 同步要求文档可匿名访问或地址内含访问凭据；拉取失败会在同步历史中记录原因。
- 网络不通（三方平台在内网）时，请先确认部署环境到三方平台地址的连通性。
