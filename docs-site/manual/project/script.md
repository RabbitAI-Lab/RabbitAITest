# 公共脚本

公共脚本是项目级的前后置脚本库：把常用逻辑（变量预处理、签名计算、断言准备等）沉淀为可复用脚本，前后置 script 处理器通过 `scriptRef` 引用，构建期自动展开，避免到处复制粘贴。

## 概念

路径：`/settings/public-scripts`（项目 › 设置 › 公共脚本）。页面为列表 + 编辑抽屉 + 在线调试抽屉；列表区分内置/自定义二态展示。

脚本在执行引擎的 **quickjs 沙箱**中同步运行：无任何 IO 能力，仅暴露白名单 API，超时强制中断，保证平台安全。

## 操作流程

1. 进入 项目 › 设置 › 公共脚本，点击「新建脚本」；
2. 在编辑抽屉中编写脚本正文并保存；
3. （推荐）打开在线调试抽屉验证脚本行为；
4. 在接口用例/场景的前后置处理器中选择「引用公共脚本」（scriptRef），保存即完成挂接；
5. 执行时构建期将 scriptRef 展开注入，脚本随请求在沙箱内执行。

## 公共脚本 vs 内联脚本

| 维度       | 公共脚本（scriptRef）              | 内联脚本                       |
| ---------- | ---------------------------------- | ------------------------------ |
| 复用       | 一处定义多处引用                    | 逐用例各写一份                 |
| 维护       | 修改一次全量引用处生效              | 需逐条修改                     |
| 调试       | 提供在线调试抽屉                    | 随用例执行验证                 |
| 适用       | 签名计算、公共变量预处理等通用逻辑  | 与单个用例强相关的临时逻辑     |

?> 建议：同一段脚本被第二处引用时即抽为公共脚本；引用关系在执行报告的处理器日志中可追溯。

## 可引用的位置

公共脚本可被以下位置的 script 处理器引用（scriptRef）：

| 引用位置           | 说明                                       |
| ------------------ | ------------------------------------------ |
| 接口用例前后置     | 用例级处理器，执行到该用例时运行           |
| 场景步骤前后置     | 场景中每个步骤的前后置处理器               |
| 环境全局前后置     | 环境管理第 ⑤ 区的全局处理器（ScriptRefPanel 引用），引用该环境的每次执行均生效 |

同一脚本被多处引用时，修改公共脚本即全部生效，无需逐个用例调整。

## 在线调试

编辑抽屉旁的在线调试抽屉可在保存前验证脚本：输入模拟变量、运行脚本并查看 log 输出与变量变更，避免「写完只能靠执行用例试错」。

## 沙箱 API 白名单

| API          | 说明                                     |
| ------------ | ---------------------------------------- |
| `log(...)`   | 输出日志，写入执行报告的日志区            |
| `getVar(k)`  | 读取当前变量（不存在返回空串）            |
| `setVar(k,v)`| 写入变量，供后续步骤/断言使用            |
| `envGet(k)`  | 读取执行环境的变量                       |
| `randomInt(min,max)` | 生成随机整数                     |
| `now()`      | 当前时间戳                               |

示例（生成随机用户名写入变量）：

```javascript
setVar("username", "user_" + randomInt(1000, 9999));
log("generated: " + getVar("username"));
```

## 边界与注意事项

| 限制项         | 值        | 说明                                              |
| -------------- | --------- | ------------------------------------------------- |
| 脚本大小上限   | 64 KB     | 超出无法保存                                      |
| 执行超时       | 5 秒      | 同步执行超时中断强杀，步骤失败                    |
| IO 能力        | 无        | 不能访问网络、文件系统、进程                      |
| 可用 API       | 白名单 6 个 | 仅有上表 API，无 setTimeout/fetch 等              |

!> SQL 处理器当前未启用（静态安全门禁拦截，执行时返回 CONFIG_ERROR 并明确提示），与脚本沙箱无关；如需数据处理请优先使用提取/断言处理器或脚本内变量运算。

?> 脚本属项目级资源，跨项目不可见；同一脚本可被多个用例/场景引用，修改后所有引用处即时生效。
