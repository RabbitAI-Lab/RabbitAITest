# AI 能力

RabbitAITest 内置 AI 辅助能力：管理员配置大模型接入，测试人员即可使用 AI 生成功能用例、AI 生成接口用例、AI 智能助手与提示词模板自定义。

<img src="_media/shots/ai-assistant.png" alt="AI 智能助手">

## 概念

AI 能力分四层：**系统模型设置**（管理员配什么模型）→ **个人默认模型**（我用哪个模型）→ **AI 生成与智能助手**（用模型做什么）→ **提示词模板**（生成行为如何定制）。

## 模型设置（系统级）

> 所需权限：SYSTEM_AI:READ / SYSTEM_AI:CREATE / SYSTEM_AI:UPDATE / SYSTEM_AI:DELETE

路径：`/system/ai-models`（系统 › 模型设置）。以卡片列表管理模型，支持新建/编辑（Modal）、连接测试、设为默认。

支持的供应商三家（协议统一为 OpenAI 兼容 chat/completions）：

| 供应商   | 默认 baseUrl                            |
| -------- | --------------------------------------- |
| 智谱 AI  | `https://open.bigmodel.cn/api/paas/v4`（默认供应商） |
| DeepSeek | `https://api.deepseek.com`              |
| OpenAI   | `https://api.openai.com`                |

操作流程：

1. 新建模型：选择供应商，填写模型名与 apiKey（baseUrl 预填默认值，可改）；
2. 点击「连接测试」验证配置可用性；
3. 将可用模型「设为默认」，供未绑定个人模型的用户使用。

!> apiKey 以 AES-256-GCM 加密落库：任何界面不回显；编辑时留空表示不修改密钥。请确保部署环境可访问所选供应商的 API 地址。

## 个人默认模型

路径：`/personal/ai-model`（个人中心 › 个人默认模型）。系统存在多个模型时，个人可绑定默认模型；AI 生成抽屉与智能助手默认使用该模型，也可临时切换。

## AI 生成功能用例

入口：功能用例列表（`/cases`）的「AI 生成」按钮，打开生成抽屉。

操作流程：

1. 填写需求文本，选择目标模块、用例模板与模型；
2. AI 返回**草稿卡片列表**，逐条勾选需要的草稿；
3. 点击「导入」，勾选的草稿写入用例库（成为正常用例，可继续编辑）。

AI 输出的用例等级与平台等级的映射固定为：

| AI 等级    | 平台用例等级 |
| ---------- | ------------ |
| critical   | P0           |
| high       | P1           |
| medium     | P2           |
| low        | P3           |

## AI 生成接口用例

入口：接口用例列表（`/apis`）的 AI 生成抽屉。流程与功能用例生成一致（输入需求 → 草稿勾选 → 导入），区别在于草稿为接口用例：包含请求信息，并携带**断言草稿**（断言数显示在草稿卡片上），导入后直接形成可执行的接口用例，规格（请求定义）由目标接口定义补齐。

## AI 智能助手

入口：顶栏 Sparkles 图标，打开右侧 Drawer。

- **会话栏**：多会话管理（Conversations），支持会话重命名、删除；
- **气泡流**：问答以气泡流展示，回答为 SSE 流式打字机效果，生成中可**停止生成**；
- **输入区**：Sender 输入框发送问题，可切换本次使用的模型；
- **空态建议卡**：Welcome/Prompts 提供三类起点——用例设计思路、接口故障排查、测试文档解读。

适用场景示例：梳理测试分析思路、定位接口报错原因、解读需求/接口文档等。

## 提示词模板（项目级）

路径：`/settings/ai-prompts`（项目 › 设置 › AI 提示词）。

- 项目级共享的用例生成提示词模板，按场景分两类 Tab 管理；
- 模板正文支持占位符（渲染时替换，缺失变量替换为空串）；
- 支持启用/停用与设为默认：**停用的模板不出现在生成抽屉且不可为默认**；项目无可用模板时生成抽屉回退「内置默认」模板。

## 边界与注意事项

- AI 生成结果均为**草稿**，导入前请人工审阅；导入后与普通用例无异。
- 未配置任何系统模型时，AI 生成与智能助手不可用；先由管理员完成模型设置。
- 生成质量依赖模型能力与提示词模板，建议为项目定制提示词以稳定输出结构。
- 环境变量 `GLM_API_KEY` 是**开发流程**视觉还原度比对（`pnpm visual:diff`）使用的密钥，与产品内 AI 功能配置无关，请勿混淆。
