# 测试计划

测试计划把功能用例、接口用例与自动化场景组织成一次有目标、有周期、有结论的测试活动，统一跟踪执行进度与通过率，并产出可分享、可导出的测试报告。

> 所需权限：PROJECT_PLAN:READ（查看）/ PROJECT_PLAN:CREATE（新建）/ PROJECT_PLAN:UPDATE（编辑、执行、归档）/ PROJECT_PLAN:DELETE（删除）。

## 概念

### 计划字段

| 字段                             | 说明                                                     |
| -------------------------------- | -------------------------------------------------------- |
| 名称 / 描述                      | 计划标识与说明                                           |
| 执行周期                         | 计划的开始 / 结束时间                                    |
| 标签                             | 横向归类                                                 |
| 允许重复关联（allowDuplicate）   | 同一用例是否允许在同一计划中关联多次（如多环境重复执行） |
| 自动更新状态（autoUpdateStatus） | 引擎执行结果是否自动回写用例的执行状态                   |
| 阈值判定（threshold）            | 通过率达到该百分比判定计划「达标」，默认 100             |

### 计划状态机

| 状态               | 含义             | 可执行 |
| ------------------ | ---------------- | ------ |
| NOT_STARTED 未开始 | 已创建未开始执行 | 是     |
| UNDERWAY 进行中    | 执行中           | 是     |
| COMPLETED 已完成   | 执行完毕         | 是     |
| ARCHIVED 已归档    | 归档只读         | 否     |

归档后的计划进入只读状态（服务端拒绝修改，业务码 10008 PLAN_ARCHIVED），可随时取消归档恢复。当计划组内成员全部归档时，该计划组将级联归档。

### 执行结果枚举（用例清单行）

| 结果           | 含义                         |
| -------------- | ---------------------------- |
| NOT_RUN 未执行 | 尚未执行                     |
| PASS 通过      | 执行成功                     |
| FAIL 失败      | 执行失败                     |
| BLOCKED 阻塞   | 被外部条件阻塞               |
| SKIPPED 跳过   | 被跳过（如失败停止后的余项） |

## 操作流程

### 1. 创建计划

点击「新建计划」，填写名称、描述、执行周期、标签与三项设置（允许重复关联 / 自动更新状态 / 阈值），保存后进入计划详情页。

### 2. 关联与编排用例

计划详情页提供四个页签：

| 页签     | 用途                                                             |
| -------- | ---------------------------------------------------------------- |
| 测试点   | 按「测试点」组织测试范围，用例按测试点归组管理                   |
| 用例清单 | 功能 / 接口 / 场景三类用例混排；支持批量指派执行人、批量取消关联 |
| 脑图     | 脑图模式下执行功能用例                                           |
| 报告     | 查看与导出测试报告                                               |

### 3. 执行与标记

- **列表模式执行**：在用例清单中逐条记录执行结果，可展开**步骤级面板**逐步骤记录实际结果，并与**缺陷联动**（对失败步骤直接关联 / 新建缺陷）。
- **脑图模式执行**：在脑图页签中按用例树逐条标记结果。
- **引擎真实执行**：接口用例与场景由执行引擎真实运行，人工标记与引擎执行结果汇入**统一时间线**。

### 4. 计划组与组报告

多个相关计划可组成**计划组**（如按模块拆分的多个回归计划）。组报告页提供：

- 汇总五卡：整体进度、通过率、阈值判定等核心指标；
- 成员明细：每个成员计划的进度、通过率、阈值判定徽标与报告链接；
- 组总结：人工编辑，也可基于服务端统计一键生成草稿。

### 5. 查看与导出报告

报告页签内容与导出能力：

| 能力     | 说明                                                                   |
| -------- | ---------------------------------------------------------------------- |
| 概览卡   | 通过率 / 进度 / 阈值判定 / 失败数 / 阻塞数 / 误报数（FAKE_ERROR 单列） |
| 用例明细 | 按测试点分组折叠展示                                                   |
| 报告总结 | 人工编辑 + 一键总结（服务端统计草稿）                                  |
| 分享链接 | token 免登录只读，有效期四档（1 小时 / 1 天 / 7 天 / 30 天）           |
| 导出 PDF | 打开打印友好页自动调起 `window.print`                                  |
| 导出 CSV | UTF-8 BOM 编码，Excel 打开不乱码                                       |

## 边界与注意事项

!> 归档后的计划只读：不能修改、不能执行；需要变更时先取消归档。

!> 「允许重复关联」关闭时，同一用例重复关联会被拒绝；开启后同一用例的多条关联各自独立记录结果。

!> 阈值判定只影响「达标 / 未达标」徽标展示，不改变执行行为。

!> 报告分享链接在有效期内任何拿到链接的人都可免登录查看（只读），请谨慎传播；过期自动失效。
