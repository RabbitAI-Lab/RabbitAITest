# 用例评审

用例评审是功能用例的质量门禁：创建评审 → 关联用例 → 评审人逐条标记结果 → 通过率驱动评审结论。评审通过的用例才建议进入测试计划执行。

> 所需权限：PROJECT_CASE_REVIEW:READ（查看）/ PROJECT_CASE_REVIEW:UPDATE（新建、标记、复制、结束、删除）。

## 概念

### 评审模式

| 模式 | 结论规则 |
| ---- | -------- |
| SINGLE 单人 | 任一评审人**最后标记的结果生效**（后标记覆盖先标记） |
| MULTI 多人 | **全员通过才通过**；任一失败即失败；「建议」不否决结论 |

### 标记结果枚举

| 结果 | 含义 | 是否否决（MULTI） |
| ---- | ---- | ---- |
| PASS 通过 | 用例质量达标 | 否 |
| FAIL 失败 | 用例存在缺陷，必须整改 | 是 |
| SUGGEST 建议 | 提出改进意见，但不阻塞 | 否 |
| PENDING 未评审 | 尚未标记 | — |

### 评审状态

评审有 UNDERWAY（进行中）与 ENDED（已结束）两种状态；结束后不可再标记评审结果。

## 操作流程

### 1. 创建评审

1. 进入「用例评审」页面，点击「新建评审」。
2. 填写：名称（必填）、模式（单人 / 多人）、评审人（必填，可多选）、起止时间、描述。
3. 创建后自动进入评审详情页，此时可暂不关联用例。

### 2. 关联用例

在评审详情页点击「关联用例」，通过模块树 + 用例多选器把待评审用例加入本次评审。

### 3. 逐条评审

详情页布局为**左侧用例清单 + 右侧用例速览 + 底部标记操作条**：

1. 在左侧清单选择用例（支持按结果状态过滤未评审 / 通过 / 失败 / 建议）。
2. 在右侧速览用例内容（步骤、预期结果等）。
3. 在底部操作条点击「通过 / 失败 / 建议」完成标记，可附加评语；标记**失败或建议时评语必填**。
4. 可开启自动跳转下一条，连续评审提高效率。

?> 顶部统计条实时显示 pass / fail / suggest 计数与通过率 passRate。

### 4. 查看评审历史

每条用例支持打开「评审历史」弹窗，查看该用例的历次标记时间线（谁、何时、标了什么、说了什么）。

### 5. 管理评审

列表页操作列提供：

| 操作 | 说明 |
| ---- | ---- |
| 进入 | 打开评审详情页 |
| 复制 | 复制评审（名称加 `-copy` 后缀，评审结果全部重置） |
| 结束 | 结束评审，此后不可再标记 |
| 删除 | 删除评审，仅解除用例关联，不影响用例本身 |

## 字段说明

评审列表主要列：

| 列 | 说明 |
| -- | ---- |
| 评审名称 | 点击进入详情 |
| 模式 | 单人 / 多人（悬停查看结论规则） |
| 评审人 | 头像组展示（最多 3 个 + 溢出计数，悬停看全名单） |
| 用例数 | 已关联用例总数 |
| 通过率 | 进度条 + 百分比 + 已评 / 总数 |
| 状态 | 进行中 / 已结束；超过截止时间显示「已逾期」 |
| 起止时间 | 评审窗口 |

## 边界与注意事项

!> 评审 ENDED（已结束）后不可再标记结果；如需继续评审，只能复制出新评审（结果重置）重新进行。

!> MULTI 多人模式下「建议」不会否决评审，但只要有一票 FAIL，整体即判失败。

!> 删除评审只解除关联关系，用例本体、用例内容不受影响。

!> 未选择项目或无 PROJECT_CASE_REVIEW:READ 权限时无法进入本页面；无 UPDATE 权限时仅能查看，看不到新建 / 标记入口。
