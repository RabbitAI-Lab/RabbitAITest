# 功能用例

功能用例是测试管理的基础资产，用于描述「验证什么、怎么验证、预期是什么」。RabbitAITest 提供列表与脑图两种维护模式，覆盖用例的创建、评审、执行、导入导出全生命周期。

> 所需权限：PROJECT_CASE:READ（查看）/ PROJECT_CASE:CREATE（新建、导入）/ PROJECT_CASE:UPDATE（编辑、关注、批量操作）/ PROJECT_CASE:DELETE（删除）。无 PROJECT_CASE:UPDATE 时脑图进入只读模式并隐藏编辑工具条。

## 概念

### 用例字段

| 字段              | 说明                                                        |
| ----------------- | ----------------------------------------------------------- |
| 编号              | 项目内自增，格式 `C-0000`（四位补零），导入时作为唯一匹配键 |
| 名称              | 用例标题，必填                                              |
| 等级              | P0 / P1 / P2 / P3 四级                                      |
| 标签              | 自由标签，用于横向归类与筛选                                |
| 执行状态          | 未开始 / 进行中 / 已完成 / 失败                             |
| 前置条件          | 执行该用例前需满足的条件（文本）                            |
| 步骤              | 有序步骤列表，每步含「描述 + 预期结果」                     |
| 模块              | 用例在模块树中的归属                                        |
| 创建人 / 更新时间 | 审计信息                                                    |

?> 除系统字段外，组织管理员可在组织级模板中定义**动态字段**（多种控件类型），经项目模板绑定后自动注入用例表单、列表列、高级筛选与导入导出列。

### 视图与模块

- **模块树**：左侧按模块分层组织用例，支持「是否含子级用例」开关；选中模块即过滤列表。
- **视图 Tabs**：全部 / 我关注的 / 我创建的 / 自定义视图。当前筛选组合（模块 + 关键字 + 高级筛选）可通过「另存为视图」保存为自定义视图，之后一键应用。

## 操作流程

### 1. 新建 / 编辑用例

点击「新建用例」进入编辑页，填写上表字段并保存。列表行操作提供：**编辑 / 关注（切换）/ 复制 / 分享链接 / 删除**。复制会生成新编号（如 `C-0012`）并保留原内容；分享链接复制当前用例地址供他人查看。

### 2. 列表筛选与列设置

- **高级筛选**支持：等级（P0-P3）、标签、执行状态、创建人、创建时间区间、动态字段。
- **列设置**可调整列表显示列，选择结果持久化保存。

### 3. 批量操作

勾选多行后出现批量操作条：

| 操作       | 说明                     |
| ---------- | ------------------------ |
| 批量移动   | 将选中用例移动到目标模块 |
| 批量编辑   | 统一修改等级、追加标签   |
| 批量删除   | 移入回收站               |
| 导出勾选行 | 以勾选行为范围导出       |

### 4. 导入用例（三步向导）

1. **上传文件**：支持 `.xlsx` / `.xmind` 两种格式，兼容 MeterSphere 官方模板，单次最多 5000 行。
2. **确认映射**：核对列映射与冲突策略——**相同编号跳过**（仅计数不改数据）或**相同编号覆盖**（按编号匹配存量，白名单字段全量替换并记录变更历史）。
3. **结果报告**：展示成功 / 跳过 / 失败统计，失败行有明细可供修正后重新上传。

?> 全部行先校验后原子落库：任一行校验失败时该行不导入，其余行正常处理；回收站中的用例不参与编号匹配。

### 5. 导出用例

导出弹窗支持三种格式：**Excel（默认）/ Excel 拆分 / Xmind**；可勾选导出字段；范围为**当前筛选结果**或**勾选行**。

### 6. 脑图模式

<img src="_media/shots/case-mindmap.png" alt="功能用例脑图">

切换到「脑图」视图（URL 带 `?view=mindmap` 持久化），以「模块 → 用例 → 步骤」三层树维护用例：

- 编辑在**本地工作树**上进行：可新增临时节点、重命名、标记删除；点击「保存」时收集差异批量提交，保存失败或冲突时保留本地树不丢数据。
- 常用快捷键：`Enter` 新增同级、`Tab` 新增子级、`Ctrl+Enter` 确认编辑、`M` 标记删除、`C` 复制节点、`Backspace` 删除、`F2` 重命名、方向键导航、`Esc` 取消。
- 支持撤销，上限 20 步。

!> 单条用例的步骤数上限为 100 步，超出会被拒绝，请合理拆分用例粒度。

### 7. 回收站

删除的用例进入回收站，可**恢复**回列表或**彻底删除**；彻底删除不可恢复。

!> 「AI 生成」按钮可将需求或描述交给 AI 辅助生成用例内容，需要 `PROJECT_AI:READ` 权限且已配置 AI 模型，详见 [AI 助手](manual/ai.md)。

## 边界与注意事项

!> 列表与脑图共用同一份数据：脑图保存的是差异提交，若他人在你编辑期间修改了同一用例，保存冲突时本地树会保留，请刷新后重试。

!> 导入的编号匹配只针对存量正常状态的用例；同批次文件内出现重复编号时按文件顺序处理并计入结果报告。
