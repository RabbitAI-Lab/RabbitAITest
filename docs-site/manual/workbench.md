# 工作台

工作台是登录后进入项目时的首页，聚合项目质量概览与个人工作队列，帮助测试工程师与测试管理员在一个页面内掌握「当前项目做得怎么样、我接下来要做什么」。

<img src="_media/shots/dashboard.png" alt="工作台首页">

## 概念

工作台由两部分组成：

- **概览卡片区**：四张统计卡，反映所选时间范围内的项目质量态势。
- **工作列表区**：三个页签（我的待办 / 我关注的 / 我创建的），按当前项目口径聚合条目，点击条目直达对应详情页。

所有数据均以**当前选中项目**为口径；切换项目后工作台自动刷新。

## 操作流程

### 1. 调整统计口径

1. 页面顶部通过「近 3 天 / 近 7 天」切换时间范围，概览卡随选择即时刷新。
2. 点击右上「卡片设置」，可对每张卡片单独设置展示方式：

| 选项 | 效果 |
| ---- | ---- |
| 不展示 | 该卡片从首页隐藏 |
| 半屏 | 默认布局，两卡一行 |
| 全屏 | 该卡片独占一行 |

?> 卡片布局偏好按用户持久化保存，下次进入工作台自动套用，无需重复设置。

### 2. 处理我的待办

「我的待办」页签提供三个子筛选：

| 子筛选 | 内容 |
| ------ | ---- |
| 待我评审 | 我是评审人、尚未给出结果的用例评审条目 |
| 我的执行 | 指派给我执行的测试计划条目 |
| 我的缺陷 | 指派给我处理的缺陷 |

「我的执行」行的左侧会附带资源类型徽标（功能 / 接口 / 场景，三色区分），便于快速识别要执行的是哪类资产。

### 3. 跟踪我关注的

「我关注的」页签展示你在用例、测试计划、用例评审、接口用例、场景、缺陷上点击过「关注」的对象，提供七维度子筛选：**全部 / 用例 / 测试计划 / 用例评审 / 接口用例 / 场景 / 缺陷**（筛选在服务端按类型过滤）。在各功能列表的行操作中点击「关注」即可将对象纳入此列表。

### 4. 回看我创建的

「我创建的」页签聚合你创建的六类对象：**用例 / 评审 / 计划 / 缺陷 / 接口用例 / 场景**，适合作为个人产出索引。

## 字段说明

### 概览卡

| 卡片 | 主数值 | 副文案 |
| ---- | ------ | ------ |
| 用例总数 | 项目功能用例总数 | 筛选期内新增条数 |
| 评审通过率 | 已评审用例的通过率（无已评数据时显示 —） | 进行中评审数量 |
| 计划执行进度 Top | 执行进度最高的进行中计划百分比 | 进行中计划名称列表 |
| 缺陷待处理 | 未完结缺陷数量 | 筛选期内新增条数 |

### 工作列表行

每行包含：类型徽标（用例 / 评审 / 计划 / 缺陷 / 执行 / 接口 / 场景）、标题、上下文摘要（如所属计划名）、时间。点击整行跳转到对应详情页。

## 常见用法

- **每日站会前**：切到「近 7 天」，快速过一遍缺陷待处理与计划执行进度。
- **开工清单**：在「我的待办 → 待我评审」清空当日评审任务；「我的执行」直接进入指派给你的计划条目开始执行。
- **关注跟踪**：对重点用例 / 缺陷点击关注后，统一在「我关注的」页签按维度回看变更。

## 边界与注意事项

!> 工作台数据以当前项目为口径，跨项目统计需切换项目分别查看。

!> 概览卡与列表数据来自服务端聚合查询，若项目内暂无对应数据，卡片显示 0、列表显示「暂无数据」，属正常状态。

!> 未选择任何项目时工作台提示「请先选择项目」，请先在顶部切换器中选择项目。
