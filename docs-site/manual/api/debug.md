# 接口调试

接口调试面向单请求的快速验证：组织请求参数、添加断言、选择环境后立即执行，执行结果实时以事件流报告呈现。调试通过的请求可一键保存为接口定义，沉淀为团队资产。

> 所需权限：PROJECT_API:READ（进入页面）/ PROJECT_API:CREATE（「保存为接口」按钮）。

<img src="_media/shots/debug.png" alt="接口调试">

## 概念

调试页由四部分组成：

| 区域         | 内容                                                                       |
| ------------ | -------------------------------------------------------------------------- |
| 调试历史     | 左侧栏，最近 20 条调试记录，点击直达对应报告                               |
| 请求行       | 协议 + 方法 + URL + 环境 + 执行按钮 + 保存为接口                           |
| 请求编辑器   | 统一 RequestEditor（七区）：参数、请求头、认证、请求体、前后置、断言、提取 |
| 断言快捷面板 | 类型 6 种 × 操作符 7 种的快速断言行编辑                                    |

## 操作流程

### 1. 发起一次调试

1. 在顶部请求行选择协议（默认 http；插件协议分组在启用后可选）。
2. 选择 HTTP 方法（GET / POST / PUT / DELETE / PATCH / OPTIONS / HEAD / CONNECT）。
3. 填写 URL：支持两种写法——
   - 绝对地址：`https://httpbin.org/get`；
   - 相对路径：`/api/pets/1` 或 `${base}/pets/1`，由所选**环境**的域名拼接（路径条件 > 模块 > 默认）。
4. 选择环境（相对路径必须选环境），点击「执 行」。

?> 变量作用域链：临时变量 > 任务参数 > 环境变量；URL 相对路径按环境域名拼接。执行后自动跳转「执行报告」页，通过 SSE 实时查看过程。

### 2. 组织请求（七区编辑器）

| 区                | 可配置内容                                                                                         |
| ----------------- | -------------------------------------------------------------------------------------------------- |
| Query 参数        | 键值对，支持行级启停                                                                               |
| 请求头 Headers    | 键值对                                                                                             |
| 认证              | basic / digest / none                                                                              |
| 请求体            | none / form_data / form_urlencoded / raw_json / raw_xml / raw_text / binary；form 行可引用项目文件 |
| 前置 / 后置处理器 | script（quickjs 沙箱，可引用公共脚本）/ wait；sql 未启用                                           |
| 断言              | 见下方断言面板                                                                                     |
| 变量提取          | 从响应 body / headers 提取到 temp / env 作用域                                                     |

?> 提交前会自动清洗：空 key 或被禁用的键值行、空期望值的断言会被剔除，无需手动清理。

### 3. 配置断言

断言快捷面板每行四个输入：**类型 → 目标（如 `$.url`）→ 操作符 → 期望值**：

| 类型              | 目标示例       | 期望值示例         |
| ----------------- | -------------- | ------------------ |
| status_code       | （无需目标）   | `200`              |
| response_header   | `Content-Type` | `application/json` |
| body_jsonpath     | `$.code`       | `0`                |
| body_regex        | `token`        | `eyJ...`           |
| response_time(ms) | （无需目标）   | `500`              |
| variable          | `orderId`      | `1001`             |

操作符：eq（等于）/ contains（包含）/ lt / le / gt / ge / regex（正则匹配）。点击「＋ 添加断言」追加行，`✕` 删除行。新断言默认为 `status_code eq 200`。

### 4. 保存为接口

调试通过后点击「保存为接口」：

1. 选择所属模块（接口定义树）。
2. 填写接口名称（默认取 URL 末段）。
3. 确认后当前调试载荷（请求 + 断言 + 前后置 + 提取）完整保存为一条接口定义，在[接口定义](manual/api/definition.md)中查看与管理。

### 5. 回看历史

左侧「调试历史」保留最近 20 条记录，每条显示方法徽标、URL 与结果状态点，点击进入对应的执行报告详情。

## 边界与注意事项

!> URL 校验规则：必须以 `http://` / `https://` 开头，或以 `/`、`${` 开头（相对路径需选择环境），否则不予执行。

!> 选择插件协议（非 http/https）时，方法 / URL / 环境行折叠，HTTP 参数 / 请求体面板不适用，请在「协议配置」页签中以 JSON 编辑 protocolConfig，由引擎转发给协议插件采样。

!> 断言失败与请求失败语义不同：断言不过时结果为 ASSERT_FAILED；请求本身失败（超时、连接错误）会给出对应错误码。
