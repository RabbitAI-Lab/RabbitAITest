# 接口定义

接口定义是接口测试的资产管理中心：以模块树 + 列表维护项目的接口清单，每个定义下派生接口用例与 Mock 规则，并通过变更历史追溯定义演进。支持从 OpenAPI / Postman / cURL 等格式批量导入。

> 所需权限：PROJECT_API:READ（查看）/ PROJECT_API:CREATE（新建、导入）/ PROJECT_API:UPDATE（编辑）/ PROJECT_API:DELETE（删除）。「AI 生成」入口需要 PROJECT_AI:READ。

<img src="_media/shots/apis.png" alt="接口定义列表">

## 概念

一条接口定义包含：名称、所属模块、方法、路径、请求规格（参数 / 请求头 / 认证 / 请求体 / 前后置 / 断言 / 提取）等。定义详情页由**头部信息 + API / CASE / MOCK 三个页签**组成：

| 页签 | 用途                                                           |
| ---- | -------------------------------------------------------------- |
| API  | 编辑定义本体的请求规格                                         |
| CASE | 管理基于该定义派生的接口用例                                   |
| MOCK | 管理该接口的 Mock 规则（详见 [Mock 服务](manual/api/mock.md)） |

## 操作流程

### 1. 新建 / 导入接口

- **手工新建**：选择目标模块，填写方法、路径与请求规格。
- **文件导入**：支持三种格式——`openapi3`（OpenAPI/Swagger）、`postman`（Postman Collection）、`rabbit`（RabbitAITest 导出文件）。导入向导先解析预览，确认后批量创建，完成后展示结果报告。
- **cURL 导入**：粘贴 cURL 命令 → 解析预览（自动带出方法、URL、请求头、请求体）→ 选择模块与名称保存为接口。

### 2. 导出接口

列表页支持导出当前项目接口定义为 `rabbit` 格式 JSON，可用于跨项目 / 跨环境迁移或备份。

### 3. AI 生成接口用例

列表工具栏提供「AI 生成」入口（需 `PROJECT_AI:READ` 权限）：基于接口定义生成接口用例初稿，人工确认后入库，详见 [AI 助手](manual/ai.md)。

### 4. 编辑定义

<img src="_media/shots/apis-detail.png" alt="接口定义详情">

在详情页 API 页签编辑请求规格（与[接口调试](manual/api/debug.md)使用同一套七区请求编辑器），头部可切换**执行环境**直接试运行。保存后定义版本进入变更历史。

### 5. 管理接口用例（CASE 页签）

接口用例基于定义派生，可在定义基础上裁剪参数、调整断言。用例与定义的差异以**八区 diff** 呈现，一眼看出用例改了什么：

| diff 区 | 内容           |
| ------- | -------------- |
| Query   | 查询参数差异   |
| Headers | 请求头差异     |
| 认证    | 认证方式差异   |
| 请求体  | 请求体差异     |
| 前置    | 前置处理器差异 |
| 后置    | 后置处理器差异 |
| 断言    | 断言差异       |
| 提取    | 变量提取差异   |

?> 定义更新后，未裁剪过的用例区域自动跟随定义，裁剪过的区域保留用例侧取值——八区 diff 让这类「部分跟随」清晰可见。

### 6. 查看变更历史

头部「变更历史」按钮打开时间线抽屉，按时间倒序查看定义的历次变更（谁、何时、改了什么），用于追溯接口演进与用例失配原因。

## 字段说明

| 列表列               | 说明                         |
| -------------------- | ---------------------------- |
| 名称 / 方法 / 路径   | 接口标识；方法以彩色徽标展示 |
| 所属模块             | 模块树定位                   |
| 用例数 / Mock 规则数 | 该定义下的资产数量           |
| 更新时间             | 最近编辑时间                 |

## 边界与注意事项

!> 删除接口定义是不可恢复操作：其下接口用例与 Mock 规则会一并删除，删除前有二次确认。

!> 导入 openapi3 / postman 时仅映射 RabbitAITest 支持的请求规格子集；解析失败会给出明确报错，不会静默丢数据。

!> 定义与用例的关系是「定义 + 差异」：修改定义后请回到 CASE 页签检查八区 diff，确认用例行为符合预期。
