# 报告与统计

每次执行（调试、接口用例、场景、测试计划）都会生成一份报告：以事件流形态实时呈现执行过程，支持钻取每一步的请求响应，并可生成免登录分享链接。统计页汇总 7/14/30 天执行趋势与失败分布。

> 所需权限：PROJECT_REPORT:READ（查看）/ PROJECT_REPORT:SHARE（生成、撤销分享链接）/ PROJECT_REPORT:EXPORT（导出）。

<img src="_media/shots/reports.png" alt="报告列表">

## 概念

### 报告类型

| 类型 | 来源 |
| ---- | ---- |
| api_debug 调试 | [接口调试](manual/api/debug.md)单次执行 |
| api_case 接口用例 | 接口用例 / 批量执行 |
| scenario 场景 | [自动化场景](manual/api/scenario.md)执行 |
| plan 测试计划 | [测试计划](manual/test-track/plan.md)整体执行 |

### 报告状态

| 状态 | 含义 |
| ---- | ---- |
| PENDING | 排队中 |
| RUNNING | 执行中 |
| SUCCESS | 全部通过 |
| FAILED | 存在失败 |
| STOPPED | 被手动停止 |
| FAKE_ERROR | 误报（被误报规则标记，单列统计，不计入真实失败） |

### 事件流视图

报告不是静态快照，而是**事件流**：执行引擎逐帧推送 `step-start / step-result / step-op / log / step-skip / item-*` 等帧（seq 单调递增），页面通过 SSE 实时渲染；断线后可续传补齐中间帧。

## 操作流程

### 1. 检索报告

报告列表支持**类型筛选**（调试 / 接口用例）与**关键字**（报告名称）检索；列表展示状态徽标、统计列与操作（进入详情 / 删除）。

### 2. 查看报告详情

<img src="_media/shots/report.png" alt="报告详情">

不同类型的报告呈现不同布局：

| 类型 | 详情结构 |
| ---- | -------- |
| api_debug | 单请求布局：请求 / 响应 / 断言结果 / 提取结果 |
| api_case | 统计卡 + 用例条目表，可钻取单条用例的逐步骤请求响应 |
| scenario | 五张统计卡（含误报单列）+ 条目表 + 步骤树与变量视图 |
| plan | 见[测试计划](manual/test-track/plan.md)报告页签（另有概览 / 分组明细 / 总结 / 导出） |

### 3. 分享报告

详情页「分享」打开分享弹窗：

1. 选择有效期（四档）：**1 小时 / 1 天 / 7 天 / 30 天**。
2. 点击「生成链接」，token 链接自动复制。
3. 已生成的链接集中在列表中管理：**复制** / **撤销** / 到期自动标记「已过期」。

?> 分享链接为免登录只读页：拿到链接的任何人（无需账号）在有效期内都可查看报告；撤销后立即失效。

### 4. 查看统计

「报告统计」页（`/reports/stats`）提供项目级趋势分析：

| 视图 | 内容 |
| ---- | ---- |
| 执行趋势 | 近 7 / 14 / 30 天执行量与结果走势 |
| 类型分布 | 各报告类型的数量占比 |
| 失败 TOP5 | 失败次数最多的五个对象排行 |

### 5. 删除报告

删除报告会**级联清理**报告本体及其分享链接、任务、条目、事件帧；执行历史不再可查。

## 边界与注意事项

!> 事件流数据在 Redis Stream 中保留 24 小时（TTL）：过期后报告汇总数据仍可查，但逐帧事件明细可能不再完整。

!> 分享链接的密码保护与导出能力不在当前版本范围内；撤销 / 过期 / 不存在的 token 统一呈现「分享链接已过期或不存在」。

!> 误报（FAKE_ERROR）由误报规则标记产生，入口见[自动化场景](manual/api/scenario.md)；误报单列展示，不计入真实失败数。
