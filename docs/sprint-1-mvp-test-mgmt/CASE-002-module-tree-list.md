## 1. 概述

### 1.1 功能定位

用例管理的主导航升级：左侧模块树（scene=case）+ 右侧全能力列表。树与列表构成此后所有 case 域页面的骨架（评审/计划关联复用）。

### 1.2 范围边界

| 能力                                                                                                                                         | P1 ✅ | 后续                                   |
| -------------------------------------------------------------------------------------------------------------------------------------------- | ----- | -------------------------------------- |
| 模块树：根节点预置（默认模块不可删名可改）、增/改名/删（子树用例上移根）、同级排序、拖拽移动（子树整体）、节点用例计数（含子树）、关键字定位 | ✅    | 跨场景拖拽（api 树 Sprint 2 组件复用） |
| 列表筛选：模块（单选+含子级开关）、名称、等级、标签、状态、创建人、更新时间区间、**动态自定义字段**（visible_in_list）                       | ✅    | 全文检索（P4 评估）                    |

| 行操作：编辑、关注/取关、分享（复制链接含模块与筛选参数）、复制（新 num 草稿）、删除（回收站）                                               | ✅    | —                                      |

PROJ-002 字段引擎（动态筛选参数序列化）；树组件第 10 天前合入。

## 2. 业务逻辑

- 树删除：任一子节点或本节点下有用例 → 确认弹窗「用例将移至默认模块」；删除即子树级联删除节点。
- 拖拽校验：不可拖入自身或后代（环检测）；移动只改 parent/order，用例归属随节点。
- 复制用例：名称追加「_copy」、新 num、状态=草稿、tags/字段值深拷贝、关联关系（依赖/评审/计划）**不**复制。
- 关注：Follow 表（entity 多态）；关注后变更消息（Sprint 5 通知消费该表，本迭代仅列表徽标）。
- 分享链接：`/cases?module=&view=&filters=` URL 编码；未登录跳登录后还原参数。
- 视图：每用户每场景私有（user_preference JSONB），上限 10 个。

## 3. UI/UX 设计（高保真 docs/design/CASE-002-module-tree-list/）

- 布局：左 240px 模块树面板（收起按钮、树工具栏：+同级/+子级/刷新、右键菜单=重命名/删除/排序、底部计数汇总）；右列表区（沿用 Sprint 0 骨架升级）。
- 筛选条两行：首行=视图 Tabs（全部/我关注的/我创建的/+自定义）+ 搜索框 + 展开高级筛选；次行（展开后）=等级/标签/状态/创建人/更新时间/动态字段（按模板 visible_in_list 渲染）。
- 列设置齿轮：勾选显示列（静态列+动态字段列），记用户偏好。
- 批量条：勾选行后顶部浮现（已选 N 项｜移动/复制/删除/导出/批量编辑）。
- 空态：模块空树引导建模块；列表空态区分「无筛选结果/模块为空」。

## 4. 技术架构

- 数据模型（已建齐）：ModuleNode(scene/parent/name/order) 、Follow、UserPreference(key JSONB)。
- 端点：`GET/POST /api/v1/projects/{pid}/modules?scene=case`、`PUT/DELETE .../modules/{id}`、`POST .../modules/{id}/move`；CASE-001 列表端点扩展 query（moduleId/includeChildren/tags/status/creator/updatedRange/fields JSON + viewId）；`POST /api/v1/projects/{pid}/views`、`PUT/DELETE .../views/{id}`；`POST .../cases/{id}/copy`、`POST .../cases/{id}/follow`、`DELETE .../cases/{id}/follow`；`POST .../cases/batch-(move|delete|update)`。
- zod：moduleUpsertSchema、moduleMoveSchema（含环检测服务端复验）、caseListQuerySchema v2（动态字段参数白名单来自模板）、viewUpsertSchema。
- 索引：FunctionalCase(moduleId, deletedAt) 复合（迁移补建）。
- 权限点：PROJECT_CASE:READ|CREATE|UPDATE|DELETE；树管理复用 PROJECT_CASE:UPDATE。
- 前端：`<ModuleTreePanel scene/>`（packages/ui，树状态 Zustand）；列表筛选状态机 hook `useCaseFilters`；URL query 双向同步。
