判定口径：
- **已覆盖**：该能力行的交互行为或契约被至少一条自动化断言验证（Playwright 三类断言 / jmx 采样器四项断言 / Vitest 契约断言）。
- **部分覆盖**：行内已覆盖主要子能力，但存在「从严判定」的子能力缺口（如批量操作只测了删除、用户管理只测了创建）。
- **完全缺口**：整行无任何自动化断言。
- 证据缩写：`e2e:{用例名}` = tests/e2e 对应用例；`jmx:{采样器}` = tests/api 对应采样器；`unit:{describe}` = packages/shared/src/__tests__/s1.test.ts。
