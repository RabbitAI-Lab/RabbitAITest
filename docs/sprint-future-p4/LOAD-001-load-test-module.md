## 1. 概述

### 1.1 功能定位

复刻 MeterSphere v3 社区版的**性能测试占位口径**：社区版本就没有独立性能测试模块，代码中仅保留企业版方向占位（`menu.PERFORMANCE_TEST_*` 菜单配置项、`PROJECT_APPLICATION_PERFORMANCE_TEST` 权限点、资源池 DTO `loadTest` 字段）。本项目按同一口径交付占位资产——**模块开关（默认关）+ 保留权限点 + 占位导航与页面 + 资源池 DTO 占位字段**，不交付任何压测内核（AGENTS 门禁 6 红线：执行引擎不做性能压测内核；标准版不做性能测试）。

### 1.2 范围边界（能力行 → §5 用例映射）

| 能力                                                                   | P1 ✅ | 后续                                   |
| ---------------------------------------------------------------------- | ----- | -------------------------------------- |

| 权限点 `PROJECT_LOAD:READ` 声明（保留位，预置组映射见 §4）             | ✅    | 企业版激活时扩展 CREATE/EXECUTE 等动作 |

## 2. 业务逻辑

- **开关链路**：项目设置-信息页 → 模块开关「性能测试（企业版方向）」→ PUT 项目信息（modules 含 `load`）→ 前端 zustand 项目信息刷新 → LeftNav 按 `module === "load" && modules.load === true && canGlobal("PROJECT_LOAD:READ")` 过滤显隐。
- **占位页**：`/load` 渲染企业版方向空态卡片（说明文案 + 规划能力清单置灰列表 + 规格文档链接），无任何可操作数据面。
- **默认值语义**：`modules.load` 缺省视为 **false**（与 case/api/plan/bug 缺省 true 相反，UI 层显式按 key 白名单区分），存量项目 JSON 不迁移（缺键即关，零迁移成本）。
- **边界与异常**：无权限用户即使项目开启开关也看不到导航（双门控）；开关关闭不删除任何数据（占位页本无数据）。

## 3. UI/UX 设计

- 高保真原型：`docs/design/LOAD-001-load-placeholder/index.html`（含三态：开关关闭（导航无组）/ 开关开启（导航+占位页）/ 无权限（开关开启但导航隐藏））。
- 占位页结构：PageHeader「性能测试」+ 空态卡片（企业版方向标识 Tag + 说明 + 置灰能力列表：压测场景编排/分布式压力节点/压测报告对比）+ 「查看规划」链接到本规格。
- 项目设置信息页：模块开关区新增「性能测试」行，Tag 标注「企业版方向」，交互同既有四键（Switch）。

## 4. 技术架构

- **权限点**（packages/shared/src/permissions.ts）：新增 `PROJECT_LOAD:READ`，注释标注「S-future LOAD-001 保留位（企业版方向占位）」；预置组映射：`SYSTEM_ADMIN` 授予（项目级管理员组若存在同步授予——实现时以 permissions.ts 现状为准并在走查登记）。
- **模块开关**（schema 不动）：`Project.modules` Json 保持既有 default；`settings/info` 页 MODULES 列表增 `{key:"load", defaultOn:false, enterprise:true}`；LeftNav `NavItem.module="load"`。
- **路由**：`apps/web/src/app/(console)/load/page.tsx`（纯静态占位页，无 API）。
- **资源池 DTO**：`pool.service.ts serializePool` 增 `loadTest: false, uiTest: false` 两占位字段（后者属 UIT-001，同 PR 一次交付，两规格各自登记）。
- **API 契约**：无新增端点（复用项目信息 PUT 与资源池 GET 既有信封）。

## 5. 测试用例

| 编号        | 类型   | 前置                  | 步骤                                      | 预期                                                                                |
| ----------- | ------ | --------------------- | ----------------------------------------- | ----------------------------------------------------------------------------------- |
| LOAD-001-T1 | Vitest | 权限点清单            | 断言 PROJECT_LOAD:READ 在 permission 常量 | 存在且未被预置拒绝                                                                  |
| LOAD-001-T2 | jmx    | admin 会话            | PUT 项目信息 modules.load=true 后 GET     | 信封 code=0，modules 含 load=true                                                   |
| LOAD-001-T3 | jmx    | 无项目权限用户会话    | 同上 PUT                                  | 403（权限面复用项目信息端点既有权限，登记豁免单独断言）                             |
| LOAD-001-T4 | e2e    | admin 登录 + 目标项目 | 设置页开启开关→看导航→进 /load            | UI：导航组与占位页可见；Console：无 error；接口：PUT 信息 200 且 GET 回显 load=true |

四类场景映射：正常路径=T2；权限= T3；校验（422）=登记豁免（modules 为 Json 布尔面，非法载荷走既有 zod 422，无本规格专属码）；分页=不适用（无列表面，登记）。

## 6. 竞品深度对标

MeterSphere v3 社区版以**代码占位**（配置项/权限点/DTO 字段）标记企业版方向，不在社区版运行任何压测逻辑；本项目采用同构策略且把「菜单配置项」具象为 `Project.modules` 键（本项目既有模块开关机制），保证企业版激活时只需替换占位页为真实模块、开关语义与权限点可直接复用。差异化决策：基线权限点动作集为 APPLICATION 设置族，本项目收敛为 `READ` 保留位（无设置面可管）。
