## 1. 迭代目标

**为平台接入大模型能力：统一模型网关（三供应商）+ AI 生成功能/接口用例 + 顶部智能助手 + 提示词自定义。**

端到端可演示路径（浏览器操作主线）：

```
系统管理→模型设置：添加模型（DeepSeek/OpenAI/智谱，OpenAI 兼容协议）→ 连接测试 → 设默认
→ 功能用例列表「AI 生成」：输入需求 + 选模块 + 选提示词模板 → 生成草稿 → 勾选导入
→ 接口定义「AI 生成」：按单条接口定义生成接口用例草稿 / 按 OpenAPI 文档批量生成 → 导入
→ 顶栏 AI 助手：会话列表 + 流式对话（SSE 打字机）→ 会话管理（新建/重命名/删除）
→ 项目设置→AI 提示词：模板 CRUD（功能用例/接口用例两类 scene、设计方法、默认模板）
```

四条成功判定：

| 维度           | 目标                                                                                         | 判定方式                                                         |
| -------------- | -------------------------------------------------------------------------------------------- | ---------------------------------------------------------------- |
| 网关可用且安全 | 三供应商 OpenAI 兼容统一客户端；apiKey AES-256-GCM 加密落库、响应永不回显；baseUrl SSRF 守卫 | 加密 roundtrip 单测；守卫矩阵单测（内网/元数据/环回全拒）        |
| 生成可导入     | 功能用例/接口用例草稿 JSON 生成→容错解析→勾选导入，经既有创建端点落库（权限不绕过）          | e2e 全链路（mock 供应商确定性输出）；AiGenRecord 留痕            |
| 助手流式可用   | 顶栏入口侧滑面板；SSE 流式打字机；会话持久化（个人级，软删）                                 | e2e 对话断言（UI+Console 无错+网络帧）；断线重连复用 stream 惯例 |
| 提示词可定制   | 项目级模板 CRUD；`{{requirement}}/{{module}}/{{design_method}}` 占位符渲染；默认模板语义     | 单测渲染矩阵；e2e 模板二态（默认/自定义）                        |

**本迭代不追求**：AI 工具调用引擎（MeterSphere ChatToolEngine/DateTimeTool 等深水区，登记 Backlog）、个人级模型设置入口（挂个人中心 SYS-007，S5 交付后接入）、场景用例 AI 生成（登记 Backlog，AI 生成主口径=功能用例+接口用例，与基线一致）、多模态/图片理解、Token 计量计费。

## 3. 范围排除（防蔓延红线）

- **不做**：AI 工具调用引擎与内置工具（DateTimeTool/JvmTool/IntegrateTool 对标差异登记）、个人级模型设置（SYS-007 个人中心 S5 后接入）、场景用例/测试计划 AI 生成、AI 生成历史回滚再导入（留痕只读）、文档解读/截图理解、语音输入、Token 计量与配额、企业版模型代理共享
- 生成范围限定**功能用例 + 接口用例**（S1/S2 已交付能力）；mock 供应商端点进 apps/mock（测试确定性输出，生产代码零测试标记）
- 协议仅 OpenAI 兼容 chat/completions（DeepSeek/智谱/OpenAI 三供应商实测同构）；不接 Anthropic 原生协议（登记 Backlog）
- 助手为纯对话（平台上下文注入 system prompt），不查库不执行动作——工具调用引擎为上述排除项

## 4. 验收标准（现场跑通）

1. 模型管理：系统管理→模型设置→添加（provider 三选一、baseUrl/apiKey/model）→连接测试通过→设默认；apiKey 在任何响应中只显 `sk-****` 尾 4 位
2. 功能用例 AI 生成：用例列表→AI 生成→输入需求+选模块+选模板→生成→草稿卡片→勾选导入→用例列表出现且模块/字段正确
3. 接口用例 AI 生成：接口定义页选中 API→AI 生成→草稿（请求差量+断言建议）→导入；批量模式贴 OpenAPI JSON→解析 N 接口→生成→导入
4. AI 助手：顶栏图标→面板→选会话→发消息→打字机流式输出→刷新页面历史仍在；新建/重命名/删除会话
5. 提示词模板：项目设置→AI 提示词→新建模板（scene/占位符/设计方法）→设默认→生成抽屉默认选中；同 scene 默认唯一
6. SSRF 守卫：baseUrl 填 `http://169.254.169.254`/`http://127.0.0.1:8080`/`http://10.0.0.1` → 422 70422
7. 权限二态：PROJECT_MEMBER（仅 PROJECT_AI:READ）可见生成入口可用生成、模板管理只读（新建/编辑/删除隐藏+直发 403 10003）；SYSTEM_AI 仅系统管理员
8. 自动化测试齐备（rules/testing.md）：每功能点 Vitest + JMeter（四类场景×四项断言）+ Playwright（三类断言）全绿

### 7.2 交付过程中发现并修复的缺陷（实现侧 8 处）

AiModel.baseUrl 漏 @map("base_url")（列名与 migration snake_case 错位 → seed P2022）；jmx 生成器 setup 采样器漏 sampler() 包裹（T0 未生成 → 全链 401/变量未替换）；mock baseUrl 缺 /ai 路径前缀（web 拼出 /chat/completions → 供应商 404→502）；next start 旧构建缓存（service 修复不生效——改后必须 rebuild）；JSONPathAssertion 恒按正则匹配（sk-**** 非法正则静默失败）；Jayway 无 length 简写（改确定性元素断言）；SSE 流式分片切断中文（整 body contains 中文不可靠——断帧结构+落库完整文本）；批量 OpenAPI 解析失败透出 40422（统一映射 70503）。环境侧：多 worktree 并存端口互抢（4000 开发/s6 占用、4010 曾被 s6 web 占用 → jmeter 栈 mock 迁 4020）；docker daemon 挂起（栈脚本 redis 可达性检查优先，本地 redis-server 兜底）；jmeter 栈缺 RABBIT_USER_LIMIT=1000（30 计划后注册 422）。
