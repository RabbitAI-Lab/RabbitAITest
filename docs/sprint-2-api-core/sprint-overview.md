## 1. 迭代目标

**8 周「测试域核心可用」的后一半：把 Sprint 0 的单请求调试升级为接口测试完整闭环。**

端到端可演示路径（浏览器操作主线）：

```
建环境（变量/多域名条件/HOST）→ 建接口定义（模块树）→ API 页签完整参数体系调试
（变量渲染/提取/断言 6 种/前后置）→ 保存为接口用例 → 用例批量执行（选环境+默认池）
→ 任务中心看进度/失败重跑 → 接口报告（用例级+步骤级钻取）→ 分享链接只读访问
→ Mock 规则配置并命中（独立 Mock 服务）→ 功能用例/测试计划关联接口用例
```

四条成功判定：

| 维度         | 目标                                                                        | 判定方式                                                             |
| ------------ | --------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| 参数体系正确 | `${var}` 渲染/域名条件匹配/提取写回环境变量/断言 6 种端到端生效             | E2E 断言实际发出的请求 URL/负载与提取回显；断言失败与成功两态        |
| 执行调度可靠 | api_case 批量任务（串行+失败停止）、并发槽随池配置生效、停止/重跑/引擎重启不丢任务 | MAINFLOW-s2 全绿；任务中心状态机与重跑副本断言                       |
| Mock 可用    | 规则（头/Query/REST/体）命中返回配置响应、跟随 API、未命中 404、规则热更新  | 独立 Mock 服务（:4000）真实命中断言（UI+HTTP 双路径）                |
| 域间解耦     | case/plan 经 Provider 读 api_test 域；engine 无 DB 依赖；HTTP only          | code review 门禁 + 依赖方向单测（api-client 路径审计）               |

**本迭代不追求**：场景编排（S3）、协议插件化（PLUG-002，引擎冻结 HTTP only 至本迭代结束）、Swagger 定时同步（S6 API-011）、误报规则（S3 API-010）、报告批量导出（RPT-003）、K8S 资源池（ENTP-006/EXEC-004）。

## 3. 范围排除（防蔓延红线）

- 不做：场景一切功能（S3）、AI 生成用例（S7）、Swagger 定时同步与 URL 同步（S6 API-011）、HAR/JMeter 格式导入（S3 API-009）、误报规则（S3 API-010）、报告批量导出与 PDF（RPT-003/PLAN-005）、环境组与项目级全局参数（S5 PROJ-006）、Git 文件存储库（S5 FILE-001）、API 文档分享（登记 Backlog，随 S3 导入导出扩展评审）、XPath 提取与断言（XML 解析依赖重，登记豁免）、Python 脚本前后置（P2 起，engine-execution-architecture §4）
- 不做任何 ENTP 功能：多资源池/K8S 池（License 门控，UI 禁用+登记）；数据库数据源仅内置 PostgreSQL（MySQL 等驱动=插件化口径，PLUG-002 后）
- 引擎冻结 HTTP only（本迭代结束前不接协议插件）；Mock 服务不外调第三方（「Mock 地址外调」为使用口径非服务能力）

## 4. 验收标准（现场跑通）

1. 环境变量 `${host}` 在定义/用例/调试三处渲染一致；HTTP 域名按「路径条件>模块条件>默认」匹配；HOST 映射生效（请求实际打到映射地址）
2. 提取（JSONPath/正则）结果写回环境变量并在报告显示；断言 6 种（状态码/响应头/响应体 JSONPath/响应体正则/响应时间/变量）成功与失败两态断言可见
3. 前置脚本（JS 沙箱 log/vars）、SQL（PostgreSQL 取变量）、等待三类前后置可编排；脚本错误任务失败（SCRIPT_ERROR）不静默
4. 用例批量执行：勾选 N 条→选环境→串行执行+失败停止开关生效；任务中心实时状态；失败任务一键重跑生成新副本
5. 报告：用例级列表（通过/失败/耗时）+步骤级钻取（渲染后请求快照/响应/断言表/提取值/日志）；分享链接免登只读+过期失效；保留期外报告被定时清理
6. Mock：配置规则后 `http://127.0.0.1:4000/mock/{项目号}{path}` 命中返回配置响应（含延迟）；跟随 API 取定义响应；改规则后立即生效（快照失效重载）；未命中 404（code 40401）
7. 文件：JAR 上传默认禁用、启用后可在 form-data/binary 引用执行；危险类型拒收；文件大小受系统参数限制
8. 权限：仅 `PROJECT_API:READ` 用户接口定义只读（新建按钮隐藏+直发 403 code 10003）；`PROJECT_ENV`/`PROJECT_FILE`/`PROJECT_EXEC_TASK` 同口径
9. 自动化测试齐备（rules/testing.md）：每功能点 Vitest + JMeter（四类场景×四项断言）+ Playwright（UI/Console/接口三类断言）全绿；新增主链路 E2E MAINFLOW-s2（环境→定义→调试→用例→批量执行→任务中心→报告→分享）
10. Sprint 收尾交付（AGENTS.md 门禁 9）：commit + push 远程、远端 CI 全绿、本概览交付表更新、changelog 追加
