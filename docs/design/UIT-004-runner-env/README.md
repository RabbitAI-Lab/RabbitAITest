## 设计要点（对照规格）

1. 双轨：内置 runner（全局唯一、只读）+ 项目 runner（npm 精确版本、项目隔离目录）；未配置→回落内置（画板二隔离对照块走查此语义）。
2. 隔离四级在 UI 的落点：抽屉只列本项目；跨项目访问=404（规格 §3.3）；磁盘分域与引擎归属校验不在 UI 面（走查 API 用例 T05）。
3. 预检语义：fail=必然失败项（chromium/node/runner 包/磁盘）阻断任务并落 runner-check 帧；warn（ffmpeg、npm registry 非安装场景）只提示不阻断——画板三/五的 ⚠ 行文案显式写「不阻断」。
4. 安装安全：registry 固定官方不可改（表单只读呈现）；版本白名单 `^\d+\.\d+\.\d+$`；详见规格 §4。
