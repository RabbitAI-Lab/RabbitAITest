## 选定设计（方向 A 浅色精修 + 第①②③轮修订）

1. **侧栏分组可折叠**：多项组分组头（chevron）点击折叠；默认展开当前所在域分组与系统设置组；分组头不显示数量角标（第④轮修订）
2. **主色克制**：`#574BFF` 仅出现在激活项（淡底 + 左色条/顶色条），hover 一律中性灰，非激活图标灰显；ENTP-004 动态主色保留
3. **收起交互**（第③⑧⑨轮修订）：分割线中间的小圆钮点击后**侧栏整体隐藏**（不显示图标窄条）；内容区**左缘悬浮小圆钮**（absolute 骑线、不占布局宽度，与分割线小圆钮同款视觉）点击恢复；三域均支持，切换域时侧栏自动展开
4. **单项组分组头**（第③⑥轮修订）：仅「工作台」保留无分组头直点；任务中心、性能测试、UI 测试等其余单项组**渲染分组头**（可折叠，窄条模式显示分组图标+浮层），与多项组节奏一致
5. **窄条模式分组图标 + 浮层**（第③轮修订，**已被第⑧轮替代移除**）：~~收起成 56px 图标条~~；第⑧轮起收起=侧栏完全隐藏、左缘贴边展开钮，无图标条与浮层
6. **系统设置与组织管理入口迁至右上角头像下拉**（第①⑤轮修订）：左侧菜单不再出现「系统设置」「组织」组；头像下拉 = 个人中心 / **组织管理** / **系统设置**（均权限门控）/ 退出登录
7. **域侧栏隔离，三域并列**（第①⑤轮修订）：
   - 进入 `/system/*` → 系统域：侧栏只显示系统设置 10 项 + 「返回项目」；顶栏切换器替换为「系统设置 · 跨项目 · 平台级」标识
   - 进入 `/org/*` → 组织域：侧栏只显示组织管理 5 项（项目管理/成员管理/部门管理/用户组/模板管理）+ 「返回项目」；顶栏**保留组织切换、隐藏项目切换**，附「组织管理 · 组织级 · 跨项目」标识
   - 域由激活标签的路径前缀决定（`/org` / `/system` / 其余=项目域），标签跨域共存切换
8. **内容区多标签页**（第②轮修订，浏览器式）：
   - 左侧菜单点击 = 打开标签并激活；可同时打开多个（上限 20，超出提示拒绝）
   - 标签点击切换、× 单个关闭（hover 显现，激活常显）；**工作台为固定标签不可关**
   - **批量关闭**：标签右键菜单或标签栏右侧「批量」下拉 → 关闭其他 / 关闭右侧 / 全部关闭（保留工作台）
   - 关闭当前激活标签 → 自动激活相邻（右侧优先，其次左侧）
   - 标签溢出横向滚动（**不显示滚动条**，支持滚轮横滚）；**域联动**：系统页标签（/system/*）激活时侧栏/顶栏自动切系统域，项目页标签切回项目域
   - 标签与侧栏激活态双向一致（当前标签路径高亮侧栏菜单项）

## 实现口径备忘（供规格文档起草）

- 组件改动面：`LeftNav.tsx`（折叠态 + 单项组无头 + 三域渲染 + 窄条分组浮层）、`TopBar.tsx`（头像下拉加组织管理/系统设置两项 + 三域上下文切换）、`(console)/layout.tsx`（三域路由分支：`/org` `/system`）、新增 `TabBar.tsx` + 布局嵌套；侧栏收起钮=分割线小圆钮（absolute 悬浮，antd 无现成组件需自绘）
- 多标签状态：Zustand multi-tab store（`tabs: {key,title,icon,realm,pinned}[]` + `activeKey`）；`sessionStorage` 刷新恢复；标签上限 20
- **页面保活（关键决策）**：默认**不保活**——切换标签即路由切换、组件重挂载（与浏览器标签的本质差异，需在规格中向用户明示）；表单页防误关（关闭含未保存表单的标签时二次确认）列为 P2
- 权限：头像下拉「组织管理」按 `ORG_*:READ` 任一权限点、「系统设置」按 `SYSTEM_*:READ` 任一权限点显隐（SYS-004 口径）；各域内菜单权限过滤逻辑不变
- 路由判定：`/org*` → 组织域、`/system*` → 系统域、其余 → 项目域；标签 key 即路由路径，URL 与激活标签双向同步（支持直接输入 URL / 刷新恢复）
- e2e 影响：侧栏 `data-testid` 全保留；原型已预置 `tab-bar`/`tab-{path}`/`tab-close-{path}`/`tabs-ops`/`rail-toggle`/`rail-expand`/`menu-org-management` testid；需新增多开/单关/批量关/三域联动/收起展开用例；`test:visual` 快照与还原度比对基线需重建
- 折叠展开状态持久化：localStorage（键含项目/用户维度）
