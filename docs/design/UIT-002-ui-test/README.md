# UIT-002 UI 测试模块 · 高保真原型

- 画板一 · UI 用例列表（`/ui-test` 默认页：搜索+新建+元素库入口+批量执行；步骤数/步骤摘要/最近结果 Tag）
- 画板二 · 步骤编辑器（用例名+步骤超时；步骤行=序号+指令下拉+元素选择（元素库引用，goto 行禁用）+参数+删；上限 50；保存）
- 画板三 · 元素库（表格 名称/定位方式 Tag（css·xpath·testid·text·role）/定位器/备注；新建；删除悬空语义提示）
- 画板四 · 执行报告（结论 Tag FAILED（第 3 步）·chromium·耗时；步骤时间线 ✓/✗/– 三态（✗ 行红底+期望 vs 实际+自动截图标注）；截图网格（指令截图+失败现场，失败框红边））

走查要点：指令下拉 8 项与参数列联动（goto=URL、fill/click=元素+值、assert=text、wait=ms）；元素选择与元素库名称对应；失败步骤后续步骤「未执行」态；截图网格点击放大；无 License 态回退占位页。

超出基线自主设计登记（规格 §1.4/§6）：定位方式枚举对齐 Playwright 定位器（基线 Selenium By）；P1 用表单行编辑替代拖拽编排（登记简化）；失败自动截图为基线「失败现场」的自动化加强。
