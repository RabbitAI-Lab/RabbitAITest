## 设计要点（对照规格）

1. 脚本=标准 Playwright Test 文件，AI 产出零改造粘贴即用；引擎官方 `playwright test` 子进程执行（语义零漂移）。
2. 参数注入：编辑器右侧 KV → 子进程 env `RABBIT_PARAM_*`，脚本 `process.env` 读取（代码区第 3-5 行示例呼应）。
3. 存量兼容：步骤模式（UIT-002）全保留，零迁移；不做自动互转。
4. 安全：脚本=受信载荷（权限门禁+审计+子进程隔离+总超时），不走 quickjs。
