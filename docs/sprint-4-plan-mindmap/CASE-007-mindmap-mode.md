## 1. 概述

### 1.1 功能定位

用例管理的第二种视图：脑图（模块→用例→步骤三层层级树）。与列表模式**同一数据源双向同步**（切换即刷新），支持快捷键体系建改删，节点详情侧栏编辑复用用例表单。脑图组件为通用件，PLAN-003 计划脑图执行复用（同一组件不同交互模式）。

## 2. 业务逻辑

- **数据模型**：脑图树=ModuleNode 树 × 每模块用例列表 × 每用例 steps——全只读拉取（既有端点聚合），编辑态本地树（新增节点临时 id `tmp-*`）。
- **保存事务（前端编排，后端批端点）**：收集 diff——模块：新增/重命名/删除（删除校验空）；用例：新增（名称+模块归属+steps）/更新（名称/等级/标签/steps/前置）/删除（软删入回收站）；一次「保存」按序调三个批端点（模块批→用例批），失败即停并保留本地树（重试）。冲突：保存前用版本号乐观锁（用例 version，CASE-002 既有）。
- **快捷键状态机**：焦点节点 focusNode+编辑态 editing；Enter=同级后插入（模块层/用例层生效，步骤层=新步骤行）；Tab=降级为末子（顶层模块不可再降）；Ctrl+Enter=进入节点（展开+聚焦首子）；M=当前模块下加模块；C=当前节点（模块或其父模块）下加用例；Backspace=删除（临时节点直删；已存节点入删除集，空模块/非空用例校验同列表口径）；F2/双击=重命名（步骤行内两输入）。输入框内快捷键屏蔽（isEditing 时仅 Esc/Enter 生效）。
- **导航**：方向键按布局几何移动（↑↓同层兄弟、←父、→首子）；节点折叠展开（点击三角）。
- **多选**：Ctrl+点击 增选、Shift+点击 范围选；多选工具条（删除/移动到模块）。
- **与列表同步**：保存成功后双模式缓存失效（queryClient invalidate case 列与模块树）；切列表模式带筛选保持。
- **布局（自研）**：右向树布局——根在左，逐层向右；同层垂直排布，父节点垂直居中于子块；SVG 贝塞尔连线；节点=圆角矩形（模块=蓝底、用例=白底带等级色条、步骤=窄行卡）；min-count 布局纯函数（layoutMindmap(nodes)→{x,y,w,h}[]）可单测。500 节点内不做虚拟化（折叠即裁剪，登记上限提示）。

## 3. UI/UX 设计（高保真 docs/design/CASE-007-mindmap-mode/）

- 用例页头部视图切换 Segmented「列表 | 脑图」（testid view-mindmap）；脑图模式隐藏列表工具条筛选，保留搜索（高亮命中节点）。
- 画布：左根节点「全部用例」→模块节点→用例节点（名称+等级徽标+用例数）→步骤节点（desc/expect）；节点 hover 操作（+子/+同级/删除）；顶部工具条（添加模块/添加用例/保存（含变更数徽标）/撤销/批量操作）。
- 侧栏（选中用例节点）：完整用例表单（名称/前置/步骤表/等级/标签）——复用 CASE-001 表单组件；模块节点侧栏=重命名+描述。
- 空态：无模块时根下引导「按 M 创建第一个模块」。
- 原型画板：①脑图全景（三层层级+侧栏+快捷键提示条）②多选批量态+保存确认 ③计划脑图执行态（PLAN-003 复用示意：状态色节点+S/E/B）。

## 4. 技术架构

- 组件：`packages… apps/web/src/components/mindmap/MindmapTree.tsx`（通用受控组件：`{nodes, focusId, collapsed, renderNode, onCommand}`）、`mindmap/layout.ts`（纯函数布局）、`useMindmapKeyboard`（快捷键状态机 hook）；用例页 `CaseMindmapView`（数据装配+diff 收集+保存编排）；计划执行复用（PLAN-003）`renderNode` 换状态色节点。
- 新端点（批量保存）：
  - `POST /cases/batch`（既有 CASE-002 caseBatchSchema 扩展或新增 `mindmapSaveSchema`：`{ modules:{created[],renamed[],deleted[]}, cases:{created[],updated[],deleted[]} }`，一次校验+事务，ProjectScope+CASE:UPDATE）
  - 模块批操作复用既有 `modules/batch`（如无则并入 mindmapSave）。
- shared：`mindmapSaveSchema` + diff 校验（名称/层级/上限 500 节点）。
- 前端：`/cases?view=mindmap` 分支渲染；api-client s4.ts caseMindmapApi.save。
- 错误码：`MINDMAP_TOO_LARGE 42209`（>500 节点）、`MINDMAP_CONFLICT 40905`（版本乐观锁冲突，返回冲突节点列表）。

## 5. 测试用例

- CASE-007-T1（spec 双模式同步）：列表建模块+用例→切脑图可见树→脑图 C 建用例（Tab 步骤 Enter 同级）→保存→切列表可见新用例（UI+Console+接口三类断言：保存 payload 含 created 用例）。
