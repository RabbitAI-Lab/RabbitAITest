## 教学目标

看完本集，观众能够：创建带 scope 的 APIKEY、用它调用开放 API 触发一次执行并查询结果、理解 CI/CD 流水线集成模式（APIKEY + 回调/轮询 + 报告链接）、配置第三方平台对接与 Swagger 定时同步、绑定项目代码仓库（URL 直填 / OAuth）并知道系统级代码平台配置的位置、维护全局参数。

## 录制数据准备

- 预置 1 个可执行场景；终端环境（curl 演示，字体放大）；一份演示 Swagger 文档地址；第三方平台对接以现有 integrations 支持项为准；SCM 演示用 mock 平台（e2e 同源）或真实公开仓库 URL 直填。
- 参考造数与选择器：`tests/e2e` APIKEY/开放接口相关用例（以实际文件名为准）、`SCM-001-project-repositories.spec.ts`。
