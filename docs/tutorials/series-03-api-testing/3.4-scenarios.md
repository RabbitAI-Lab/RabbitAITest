## 教学目标

看完本集，观众能够：在编排画布中搭建多步骤场景（接口/条件/循环/脚本）、用变量提取实现跨步骤传参、声明步骤依赖并调试单场景执行、导入 jmx 兼容格式、配置误报规则过滤已知噪音。

## 录制数据准备

- 预置 4~5 个可用接口（登录→查询→下单链路，走 mock 栈）；一份演示 jmx 文件。
- 参考造数与选择器：`tests/e2e/API-006-scenarios.spec.ts`、`API-007-scenario-params.spec.ts`、`API-010-false-alarm.spec.ts`。

## AI 素材提示词

### broll-3.4（T2V · 768P · 10s · Hailuo 2.3）

扁平低多边形3D插画风格，深蓝色科技空间背景（由深靛蓝到暗夜蓝的柔和渐变），主体以靛蓝色 #2545eb 与白色发光材质为主，辅以青色粒子光效点缀，电影级柔光，画面干净克制，无人物。一组大小不一的发光齿轮悬浮排列在深空中，第一颗齿轮被一圈青色光晕激活开始转动，依次带动下一颗齿轮咬合转动，能量光沿齿轮组链条式传导；链条末端的一颗小球被精准弹入一条弧形轨道，沿轨道滑行一周后回到起点，形成闭环，闭环完成的瞬间整组齿轮整体亮度提升并保持匀速转动。镜头从齿轮组侧面缓慢横移跟随能量传导方向。

负面提示：画面中不得出现任何文字、字母、数字、单词、Logo、UI 界面、按钮、水印、签名；不要人脸特写、不要畸变的手部、不要闪烁噪点、不要低分辨率噪感


## 勘误 1（2026-10-10 实现对照）

- 无 /scenarios/new 路由与拖拽画布——「+添加根步骤」下拉编排；顺序即依赖，步骤级失败策略替代依赖线

## 录制要点

- S6 步骤逐个点亮是本集高光，录屏帧率拉满、过程不剪；失败红态单独录一段拼接。
- S3 拖拽动作要慢而清晰（按住 0.5s 再移动），必要时放大画布到 125%。
- jmx 演示文件从 `tests/api/` 现有计划中取一份即可，口播不念文件名。
