## 教学目标

看完本集，观众能够：从场景或计划发起执行任务、在任务列表观察实时进度与状态流转、理解资源池与并发槽的调度模型、了解本地执行器的用途，并对失败用例快速重跑。

## 录制数据准备

- 预置 1 个可运行场景 + 1 个含接口用例的计划（约 20 个执行项，保证进度条有过程感）；资源池默认节点可用。
- 参考造数与选择器：`tests/e2e` 执行任务相关用例（EXEC/TASK 前缀，以实际文件名为准）。

## AI 素材提示词

### broll-3.5（T2V · 768P · 10s · Hailuo 2.3）

扁平低多边形3D插画风格，深蓝色科技空间背景（由深靛蓝到暗夜蓝的柔和渐变），主体以靛蓝色 #2545eb 与白色发光材质为主，辅以青色粒子光效点缀，电影级柔光，画面干净克制，无人物。四条平行的发光泳道像水渠一样横贯画面，多个白色光球同时在不同泳道中向前冲刺，各自拖出青色轨迹；泳道入口处有一道发光水闸，按固定节奏抬起放行新的光球入场；先到的光球在终点线处依次汇入一个发光的玻璃容器堆叠，容器刻度随汇入逐格点亮。镜头从泳道斜上方缓慢横移扫过全程。

负面提示：画面中不得出现任何文字、字母、数字、单词、Logo、UI 界面、按钮、水印、签名；不要人脸特写、不要畸变的手部、不要闪烁噪点、不要低分辨率噪感


## 勘误 1（2026-10-10 实现对照）

- 无 /tasks/[id] 详情页——重跑为列表行内按钮；失败重跑以打开失败报告呈现

## 录制要点

- S4 进度条推进要录完整过程（约 20~30s），可 1.5x 加速但保留起止原速。
- S5 并发槽数值以 main 分支实际默认值为准，口播不念具体数字。
- 若任务执行依赖 engine，录制前确认 engine 无残留任务（避免历史任务干扰列表画面）。
