## AI 素材提示词

### broll-7.2（T2V · 768P · 10s · Hailuo 2.3）

扁平低多边形3D插画风格，深蓝色科技空间背景（由深靛蓝到暗夜蓝的柔和渐变），主体以靛蓝色 #2545eb 与白色发光材质为主，辅以青色粒子光效点缀，电影级柔光，画面干净克制，无人物。深蓝空间中一座发光的几何悬索桥横跨画面，桥身结构与缆索泛着靛蓝微光；一排排青色光浪从画面左侧层层生成、推进并冲击桥身，桥面泛起应力光纹并轻微震颤但始终保持稳固；浪势退去后桥梁整体亮度提升一级，桥面中央缓缓升起三根高低不同的发光刻度柱，依次点亮。镜头从正面缓慢推近再轻微上摇。

负面提示：画面中不得出现任何文字、字母、数字、单词、Logo、UI 界面、按钮、水印、签名；不要人脸特写、不要畸变的手部、不要闪烁噪点、不要低分辨率噪感

## 录制要点

- 压测目标用 mock `/perf/echo`（槽位端口按 `scripts/rabbit-env.mjs`）；时长 8s / TPS 5 的小计划真实跑完，监控页不加速（曲线推进本身就是画面）。
- 阈值在演示环境适当放宽（成功率 ≥50% / P95 ≤8000ms / 平均 RT ≤5000ms，e2e 同法）——判定语义靠结论 Tag 呈现，不为绿屏硬凑严阈值。
- 引擎起压到首帧 ≤15s（e2e 口径）；若首帧慢于 8s 计划时长，录制脚本改为 15s 计划保证曲线有 2~3 个采样点。
- 收官字卡 S9 放仓库与文档站地址（与 portal 一致），口播不逐字念 URL；此镜自 6.2 迁入（系列七成为收官段）。
