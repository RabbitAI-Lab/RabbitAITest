## 教学目标

看完本集，观众能够：在元素库维护被测元素并在步骤里复用、用步骤模式编排 UI 用例并执行看报告（步骤打勾 + 截图网格）、把现成 Playwright 脚本粘贴导入执行（测试树 + trace 下载）、看懂失败报告（错误代码帧 + 失败现场截图）、用 Runner 胶囊完成六项环境自检。

## 录制数据准备

- mock 栈可用（被测页面 `/uit/demo`：用户名输入框/提交按钮/结果文案，同 e2e 口径）；演示项目 UI 测试模块开关开启（`/settings/info`，缺省开）。
- 参考造数与选择器：`tests/e2e/S11-load-uit.spec.ts`（UIT-002 段）、`UIT-003-script.spec.ts`、`UIT-004-runner.spec.ts`；演示脚本可直接复用 `UIT-003-script.spec.ts` 里的 okScript/failScript 模板（域名换演示栈 mock 地址）。

## AI 素材提示词

### broll-7.1（T2V · 768P · 10s · Hailuo 2.3）

扁平低多边形3D插画风格，深蓝色科技空间背景（由深靛蓝到暗夜蓝的柔和渐变），主体以靛蓝色 #2545eb 与白色发光材质为主，辅以青色粒子光效点缀，电影级柔光，画面干净克制，无人物。一幅由大小不一的几何矩形分块组成的悬浮画板立于画面中央，分块之间以细发光缝隙分隔；一支白色发光的光笔自动沿折线轨迹在画板上匀速游走描摹，途经的分块依次点亮青色光环；中途光笔在一个分块上描出偏移的轨迹，该分块泛起红色涟漪并轻微放大定格片刻，随后光笔退回原处重新描摹，红色褪去、青色光环恢复，整幅画板最终全部点亮。镜头从画板侧面缓慢平移推进。

负面提示：画面中不得出现任何文字、字母、数字、单词、Logo、UI 界面、按钮、水印、签名；不要人脸特写、不要畸变的手部、不要闪烁噪点、不要低分辨率噪感

## 录制要点

- 被测页面用 mock 栈 `/uit/demo`（`apps/mock`，槽位端口按 `scripts/rabbit-env.mjs`）——录制前确认 mock 起栈；教学口径不压真实第三方网站。
- 新建默认是脚本模式（S13 起），S5 的「切步骤模式 + 确认弹窗」动作要完整入镜，是双模式叙事的关键交互。
- S8 失败用例用错误期望文案制造（e2e failScript 同法），与全系列「二态」演示口径一致。
- S9 六项自检为 node / runner_pkg / chromium / disk / ffmpeg / npm_registry；warn 项文案为「不影响执行」——环境齐绿时口播提一句即可；项目级 Runner 安装只指入口不实装（npm 下载时长不可控）。
- 截图网格与 trace 卡是「可观测」卖点，逐项 spotlight；trace 下载按钮 hover 不点击（下载面板不入镜）。
