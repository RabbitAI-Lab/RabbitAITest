> 覆盖功能：AGENT-001 项目级 Agent（管理/调试台/A2A）+ AGENT-002 生成管线 + AGENT-005 技能上传。

## 教学目标

看完本集，观众能够：在项目里创建一个 Agent（角色/模式/工具白名单/技能引用）、生成与吊销 A2A 密钥、在调试台与 Agent 对话并读懂实时执行轨迹、用生成向导三步（上下文源 → 阶段勾选 → 运行）产出测试草稿，并把草稿人工审阅后批量导入用例库。

## 录制数据准备

- 模型网关可用（同 5.1）；准备一段 100 字左右的需求文本（登录模块测试要点）；演示项目开启 UI 测试等模块（缺省开）。
- 参考造数与选择器：`tests/e2e/AGENT-001-project-agents.spec.ts`、`AGENT-002-pipeline-ui.spec.ts`、`AGENT-001-a2a.spec.ts`（A2A 协议面本集只演示密钥管理，不演示外部调用）。

## AI 素材提示词

### broll-5.3（T2V · 768P · 10s · Hailuo 2.3）

扁平低多边形3D插画风格，深蓝色科技空间背景（由深靛蓝到暗夜蓝的柔和渐变），主体以靛蓝色 #2545eb 与白色发光材质为主，辅以青色粒子光效点缀，电影级柔光，画面干净克制，无人物。一只白色发光的卡通机器人剪影端坐在悬浮工作台旁，身体由圆润的几何体构成、胸前有一点青色光核；工作台四周悬浮着发光的文档薄片与棱柱状代码晶体，机器人抬起手臂牵出细密光丝，将零散的光点逐一编织成新的白色发光卡片，卡片轻盈飘起汇入上方缓缓旋转的卡片环；编织完成时机器人胸前光核亮起一圈确认光环。镜头绕工作台缓慢环绕半周。

负面提示：画面中不得出现任何文字、字母、数字、单词、Logo、UI 界面、按钮、水印、签名；不要人脸特写、不要畸变的手部、不要闪烁噪点、不要低分辨率噪感

## 录制要点

- **导航在途变量**：PR #56（Agent 独立分组菜单，Agent/技能/运行记录三子项拆页）如合入 main，入口将从「项目设置 → Agent」变为独立导航分组——S3 的入口镜头与 S6 技能库路径按录制时 main 实际导航调整，分镜其余不变。
- Agent 运行依赖模型网关可用（同 5.1 口径）；调试台 SSE 轨迹与生成进度若超 10s 可 2x 加速并在角标注明。
- S8 演示为控制时长可只勾选阶段 A（e2e 同法取消 B/C）；上下文源里勾一个代码仓库，顺带展示与 SCM-001 的联动。
- S5 密钥用演示值入镜即可；轮换/吊销各点一次，展示状态变化，不演示外部系统调用（A2A 协议面属开发者内容，不进本系列）。
- S9 导入后跳 `/cases` 验证一条即可，与 2.2 的用例列表同页，增强系列连贯感。
