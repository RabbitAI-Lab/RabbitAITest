## 教学目标

看完本集，观众能够：从源码把 RabbitAITest 一键跑起来（embedded-postgres 免外部数据库），注册账号、创建组织与项目，进入工作台开始使用；并知道如何切换外部 PostgreSQL/Redis。

## 录制数据准备

- **全新库口径**录制（先 `pkill -f pg-e2e.mjs` 等残留，见 AGENTS §4.1），体现真实首启；终端字号调大（18pt+），深色终端主题。
- 提前 `pnpm install` 完毕（安装过程不录，用字卡跳过），录制冷启动 `pnpm dev`。

## 配音脚本

| 镜号 | 文案                                                                                                                                                                                      |
| ---- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| S2   | 一条命令，从零长出一个完整的测试平台——RabbitAITest 的上手，就是种下一颗种子这么简单。                                                                                                     |
| S3   | 克隆仓库、安装依赖之后，执行 pnpm dev。内置的 embedded-postgres 会自动初始化数据库、执行迁移、写入种子数据，然后 web、engine、mock 三个服务依次就绪。整个过程不需要你安装任何外部数据库。 |
| S4   | 打开本地三千端口，注册你的第一个账号。                                                                                                                                                    |
| S5   | 注册完成，平台已经自动为你备好了个人组织与个人项目；再到组织管理里创建第一个正式项目——组织与项目，是 RabbitAITest 里数据隔离的两道边界。 |
| S6   | 现在整座工作台已经向你开放：左侧每一个模块都可以直接使用。                                                                                                                                |
| S7   | 如果你希望接入公司现有的 PostgreSQL 或 Redis，只需要在启动前设置 DATABASE_URL 与 Redis 连接环境变量，嵌入式数据库会自动让位。                                                             |
| S8   | 顺手跑一遍单测，全绿——环境就绪。                                                                                                                                                          |

## 录制要点

- S3 日志滚动很快，录制时可降低回放速度或对关键行做停顿标注（compose 时按配音对齐）；端口以当前槽位 `rabbit-env` 实际值为准，口播说「本地端口」即可，不念具体数字。
- S4/S5 表单填入用真实键入（非粘贴），每字段停 0.5s。
- S7 环境变量字卡内容需与 `docs` 中部署说明一致，录制前核对。
