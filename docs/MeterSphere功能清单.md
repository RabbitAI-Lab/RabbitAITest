# MeterSphere v3.x 功能清单

> 调研来源：官方文档 https://metersphere.io/docs/v3.x/ + 代码库 https://github.com/metersphere/metersphere （backend commit 2026-09，前端版本 3.1.0）
> 调研日期：2026-09-25
>
> MeterSphere 是 FIT2CLOUD 开源的一站式持续测试工作台。v3.x 定位为「测试管理 + 接口测试 + AI」一体化平台；
> v1/v2 中的 UI 测试、性能测试在 v3 社区版已无独立模块（代码中仅保留企业版占位：`menu.UI_*` / `menu.PERFORMANCE_TEST_*` 配置项与权限点）。
> 技术栈：Spring Boot 3.5（Java 21，模块化单体）+ Vue 3.4/Arco Design + MySQL/Kafka/MinIO/Redis，测试引擎内嵌 JMeter 5.6.3，插件机制基于 pf4j。

## 一、产品模块总览（对应前端路由菜单树）

| 一级菜单 | 内容 |
|---|---|
| 工作台 | 首页看板、我的待办、我关注的、我创建的 |
| 项目管理 | 项目与权限、模板管理、文件管理、消息管理、公共脚本、环境管理、项目日志 |
| 测试计划 | 计划（含计划组）、报告 |
| 测试用例 | 功能用例（含回收站）、用例评审 |
| 接口测试 | 接口调试、接口定义（API/CASE/MOCK）、场景（含回收站）、报告 |
| 缺陷管理 | 缺陷（含回收站） |
| 系统设置 | 系统级 + 组织级两级管理 |
| X-Pack 企业版 | 多组织、用户扩容、自定义主题、SSO 单点认证、消息模板、多资源池、企业版插件、UI/性能测试方向（详见第十二章） |
| 个人中心 | 个人信息、密码、APIKEY、本地执行、三方平台账号、模型设置 |
| 通用 | 任务中心（实时/定时）、消息通知、分享页（免登录）等 |

> **标注说明**：未标注版本的功能为社区版可用；标注【企业版】的为 X-Pack 企业版独有功能（汇总见第十二章）。

## 二、通用功能

- **项目切换**：左上角切换项目，测试计划/用例/接口/缺陷等资源按项目隔离
- **模块树管理**：添加/重命名/删除子模块、拖拽调整顺序与层级、模糊搜索、展开收起（默认模块「未规划用例」不可加子模块）
- **列表页通用能力**：条件查询、表头快捷排序与筛选、表头显示/顺序/每页数量设置、行内快捷编辑、列宽拖拽、行拖拽自定义排序、批量操作（全选当前页/所有页）、批量编辑标签（更新/追加/清空）、是否显示子模块资源开关、自定义视图（保存筛选条件）
- **回收站**：删除资源进入回收站，支持恢复与彻底删除（用例、缺陷、接口、场景均有）
- **消息通知**：右上角查看近 3 个月站内信、标记已读
- **任务中心**（系统/组织/项目三级）：
  - 实时任务：查看运行中的接口用例、接口场景、测试计划任务，查看执行详情与报告，**失败任务一键重跑**
  - 定时任务：查看/开启/关闭/删除定时任务（测试定时执行、Swagger 定时同步等）
- **其他**：界面语言切换、帮助中心、编辑页 Ctrl/Cmd+S 保存、退出登录

## 三、工作台

- **首页看板**：项目概览数据，时间筛选（近 3 天/近 7 天/自定义），可选具体项目，页面自动刷新；卡片设置（每项内容不展示/半屏/全屏）
- **我的待办**：按项目、测试计划、用例评审、缺陷等维度筛选当前用户待办
- **我关注的**：关注用例/计划等后集中展示，可按项目、测试计划、用例评审、测试用例、接口用例、接口场景、缺陷筛选
- **我创建的**：展示当前用户创建的内容，筛选维度同上

## 四、测试用例（用例管理）

### 4.1 功能用例
- **创建方式**：
  - 在线表单创建（名称、前置条件、步骤描述、预期结果、备注、模块、等级、标签、执行人、附件）
  - **脑图方式创建**（列表/脑图双模式、数据双向同步；脑图层级：模块→用例→前置条件/步骤/预期结果；支持整脑图快捷键：Enter 同级、Tab 子级、Ctrl+Enter 进入节点、M/C 添加模块/用例、Ctrl+C/X/V、Backspace 删除等）
  - **导入**：Excel、Xmind（提供模板下载；用例 ID 相同时可选覆盖或跳过）
  - **AI 生成用例**：对话式输入需求，AI 生成后勾选同步到指定模块（可自定义用例模板与设计方法；需先配置模型）
- **用例详情页 Tab**：详情（富文本编辑）、用例（关联接口/场景用例）、需求（关联第三方平台需求；JIRA 需求对接依赖 JIRA 对接插件【企业版】，TAPD/禅道为社区版插件）、缺陷（关联/新建缺陷）、依赖关系（前置/后置用例）、用例评审、测试计划、评论、变更历史
- **列表操作**：编辑、分享（复制链接）、关注（变更消息通知）、复制、删除（进回收站）、批量操作（导出/编辑/移动/复制/批量添加需求/删除）
- **导出**：Excel（默认格式/单元格拆分格式、可选字段）与 Xmind 两种格式
- **视图**：我关注的、我创建的、自定义视图

### 4.2 用例评审
- 创建评审：评审名称、**评审模式（单人评审=最后结果生效 / 多人评审=全员通过才通过）**、评审人、评审周期、关联用例
- 评审操作：逐条评审标记（通过/失败/建议+评审意见）、自动下一条、按状态筛选、批量评审、批量修改评审人、重新提审（用例变更自动转重新提审，需应用设置开启）、评审历史
- **脑图模式评审**：模块级批量评审、统一修改评审人、模块重新提审等
- 评审计划管理：复制（状态重置）、关注、快捷创建用例、取消关联、评审通过率统计
- 视图：我评审的、我创建的

## 五、测试计划

- **计划与计划组**：多个计划可归入计划组（计划组能力由 X-Pack 启用：代码经 License 校验返回 TestPlanGroupService【企业版】；文档功能手册按通用功能介绍，存在口径差异）；计划属性含名称、描述、模块、起止时间、标签
- **更多设置**：允许关联重复用例、允许自动更新状态（关联的接口/场景执行成功后功能用例状态自动更新）、**通过阈值**（达标则报告判定通过）
- **测试轮次与关联性测试**：pricing 版本对比页列明「支持测试轮次、关联性测试等测试场景」（两版均有；v3 功能手册中未见独立「轮次」配置，相近能力为「测试点」分层）
- **测试规划**：按「功能用例 / 接口用例 / 场景用例」三类组织，支持**测试点**（Test Point）分层：添加测试点、关联用例、配置是否继承上级配置
- **执行配置**：资源池选择、运行环境选择、串行/并行、失败是否停止
- **执行**：
  - 列表模式：填写实际结果、步骤执行结果、状态、评论
  - 脑图模式：快捷键（S 成功 / E 失败 / B 阻塞）、关联/新建缺陷
  - 执行失败时可新建缺陷（自动带入用例步骤）或关联已有缺陷
  - 实时更新通过率
- **定时任务**：计划可创建定时执行任务（展示于任务中心）
- **批量操作**：批量执行、修改执行人、移动、取消关联、关联/新建缺陷
- **归档**：计划可归档，列表支持「只看已归档」
- **测试计划报告**：执行自动生成报告；报告总结（可保存/一键总结）；按测试点维度查看用例明细；支持分享链接、导出 PDF；计划组同样有报告与总结

## 六、接口测试

### 6.1 接口调试
- 新建请求：默认 HTTP，其他协议通过插件扩展；8 种请求方法
- 完整请求构造：请求头、请求体（7 种格式）、Query、REST、前后置、认证
- **两种执行方式**：服务端执行（task-runner 资源池）、本地执行（本地 task-runner，需个人中心配置并检测连通）
- **cURL 导入**：可从浏览器 F12/Charles/Fiddler 复制 cURL 快速录入
- 响应展示：响应体、响应头、实际请求、控制台；上下/左右布局切换
- 请求管理：模块化组织、搜索、重命名、删除

### 6.2 接口定义（API 管理）
- API / CASE / MOCK 三页签；视图（我关注的/我创建的）+ 条件筛选
- **导入**：Swagger（URL/文件，仅 3.0）、Postman、Har、JMeter、MeterSphere 五种格式；覆盖/不覆盖模式；**Swagger URL 定时同步**（定时导入任务）
- **IDEA 插件**：本地一键同步 API 到 MeterSphere
- **API 分享**：设置分享范围、截止时间、密码访问、是否允许导出
- API 详情：定义、调试（执行后保存为新用例）、引用关系（被哪些场景引用）、变更历史
- **多协议切换**：内置 HTTP，其余协议经系统插件上传后启用（pricing 版本对比页将 WebSocket、MQTT、Thrift、GRPC 协议插件列为企业版独有，社区版列为"−"；插件文档页另标 TCP、SSH、Redis、MongoDB、AMQP 协议插件亦为【企业版】）

### 6.3 接口用例（CASE）
- 手动创建（参数、等级、状态、标签、前后置、断言，选环境执行）
- **AI 生成用例**（单条按 API 信息+提示词；批量按 Swagger/OpenAPI 文档生成多条）
- 用例详情：执行历史（查看报告/响应内容）、引用关系、变更历史
- **API-CASE 差异同步**：API 变更后 CASE 提示同步，diff 对比后一键更新

### 6.4 Mock 服务
- Mock 列表（API 详情内 MOCK 页签）：设置匹配的请求头/Query/REST/请求体与响应体
- 支持 json/xml 格式化；「跟随 API」默认取定义的响应数据
- Mock 调试（服务端/本地执行）、复制 Mock 地址供外部调用、编辑/复制/删除
- 后端内嵌 mockserver-netty 提供 Mock 服务

### 6.5 场景管理（接口自动化）
- **场景编排五大配置区**：步骤、参数（常量/列表/CSV，CSV 可本地上传或关联文件管理，作用域分场景/步骤）、前置、断言、设置（Cookie 策略、等待时间、失败规则：忽略错误继续/停止运行）
- **步骤类型（7 种）**：导入系统请求（接口/用例/场景的**复制或引用**；引用支持完全引用/步骤引用）、自定义请求（支持 cURL 导入）、循环控制器（次数/While/ForEach）、条件控制器、仅一次控制器、脚本操作、等待时间
- 步骤操作：启用/禁用、执行、复制、删除、添加子步骤、前后插入；批量展开/启用/禁用/调试/删除
- 场景级操作：执行历史、变更历史、关注、复制链接、查看报告
- **导入导出**：导入 MeterSphere/JMeter 格式；导出可选「保留引用关系」
- 列表：条件筛选、自定义视图、定时任务、批量执行/移动/复制/删除
- 执行：服务端执行（社区版仅 1 个默认资源池、单接口任务并发上限 3；新增/切换资源池为【企业版】，参考 4C8G 单节点支持 1000-2000 并发）/本地执行

### 6.6 请求参数体系（调试/定义/用例/场景通用）
- 请求体 7 种：none、form-data（含 file 类型、可关联文件管理）、x-www-form-urlencoded、json、xml、raw、binary
- **前置操作**：脚本（BeanShell-JSR223/BeanShell/Python3/Groovy/JavaScript，可引用公共脚本）、SQL（数据源取变量）、等待时间、全局前置开关；内置代码片段（获取/设置变量、取响应、导入 API、插入公共脚本、终止测试等）
- **后置操作**：脚本、SQL、**参数提取**（正则/JSONPath/XPath；随机/指定/全部匹配；存为环境参数或临时参数）、全局后置开关
- **断言 6 种**：状态码、响应头、响应体（正则/JSONPath/XPath）、响应时间、变量、脚本
- **认证**：No Auth / Basic Auth / Digest Auth（+ 脚本取 token 等方式）
- 超时与重定向设置（连接/响应超时，跟随/自动重定向）

### 6.7 内置函数
- **Mock 函数（14 类 50+）**：`@` 语法，覆盖字符串、数字、姓名、中英文文本、日期、地区、Web 变量、身份证/手机号、颜色、正则等，可叠加处理函数（md5/base64/sha/substr 等 13 种）
- **JMeter 函数（9 类 50 个）**：`${__函数名}` 语法（变量、编码、脚本、时间、属性、数字、文件、信息、字符串类）

### 6.8 接口测试报告
- 场景报告 / 用例报告两类；点击步骤查看实际请求与响应
- 报告分享（有效期于应用设置配置）、单个/批量导出、删除
- **误报规则**：项目级配置匹配规则，命中标记为误报（仅对新执行报告生效）

## 七、缺陷管理

- 创建缺陷：模板选择（本地模板或第三方平台模板，如 JIRA 默认模板）、名称、描述、附件（单文件 50MB）
- **第三方平台对接**：JIRA（JIRA 对接插件为【企业版】：需求关联、缺陷创建及双向同步）、TAPD、禅道（Zentao）（对接插件为社区版）——手动同步 + 自动同步，**双向同步**
- 同步机制（项目应用设置）：增量同步 / 全量同步、同步频率、同步开关（全量同步的执行链路由 xpack 模块增强实现【企业版】，代码注释「执行同步全量缺陷(xpack调用)」）
- 缺陷列表：同步、复制、编辑、导出、删除（本地缺陷进回收站，不影响三方平台）
- 详情页：分享、关注、详情、关联测试用例、评论（编辑/回复/删除）、变更历史
- 回收站：恢复 / 彻底删除

## 八、项目管理

### 8.1 项目与权限
- 项目基本信息（名称、描述、模块开关、资源池、启用状态；关闭模块后数据保留）
- **应用设置**：
  - 测试计划：报告保留时间、报告链接有效期
  - 缺陷管理：三方平台、项目 Key、缺陷类型、同步机制（增量/全量）、同步频率
  - 测试用例：重新提审开关、关联需求（JIRA/TAPD/禅道）开关
  - 接口测试：报告保留时间、报告链接有效期、执行资源池（多资源池为【企业版】，社区版仅默认池）、**误报规则**管理
- 成员管理（添加成员/用户组、批量操作）、项目级用户组与权限配置
- 项目版本（前端路由含项目版本入口）

### 8.2 模板管理
- 组织模板 / 项目模板两级（启用项目模板后组织模板失效且不可逆）
- **用例模板**：自定义字段（输入框/文本/单选/多选/复选/成员等类型）；社区版一套默认用例模板
- **缺陷模板**：自定义字段、本地模板最多 20 个、复制/设默认、对接三方平台字段映射（API 字段绑定）
- **工作流设置**：自定义缺陷状态与流转矩阵（初始态唯一、结束态默认「已关闭」）
- 前端路由还包含「接口模板」

### 8.3 文件管理
- 模块树组织；拖拽上传（JAR/脚本/CSV 等；JAR 上传后默认禁用，启用后可在前后置脚本引用）
- **存储库对接**：Gitea、GitHub、GitLab、Gitee（Token 连接、按分支+路径拉取文件）
- 下载、删除、移动、列表/卡片视图

### 8.4 消息管理
- **通知渠道（5 种）**：站内信、邮件（SMTP）、企业微信、钉钉、飞书（机器人 Webhook）
- 机器人管理：新建/编辑/删除/启停
- **通知场景**：测试计划（创建/更新/删除）、缺陷管理（创建/更新/删除/评论/执行完成）、用例管理（用例与评审的创建/更新/删除/评论/评审结果）、接口测试（API/CASE/MOCK/场景的增删改、执行成功/失败/误报）、定时任务（开启/关闭）
- 按事件配置接收人（创建人=操作人时不发）
- 【企业版】自定义消息模板：自定义消息内容与变量插入（用例字段/自定义字段）、实时预览、保存后预览

### 8.5 公共脚本
- 项目级脚本库：定义传递参数（支持 Mock/JMeter 函数）、多语言脚本编写、在线调试（控制台）
- 在前后置中引用执行；编辑/删除（删除影响引用用例）

### 8.6 环境管理
- 环境操作：复制、导入导出（同名覆盖开关）、编辑、删除
- 环境配置：环境变量（`${var}` 引用）、HTTP 配置（多域名按模块/路径条件匹配，优先级 路径>模块>无）、数据库（MySQL/Oracle/SQL Server/PostgreSQL，驱动经插件上传）、HOST 映射、全局前置/后置（场景级/请求级）、全局断言、TCP 配置（需上传 TCP 协议插件【企业版】）、显示设置
- **环境组**与**全局参数**（前端路由与后端模块均有环境组/全局参数能力）

### 8.7 项目日志
- 记录项目内所有用户操作（操作人/时间/对象/类型），多条件组合筛选；保留时长由系统参数控制

## 九、系统设置

### 9.1 系统级（系统管理员）
- **用户管理**：创建用户、邮箱邀请注册、Excel 批量导入；编辑/重置密码/禁用/删除；批量添加至项目/用户组/组织；社区版上限 30 个用户（代码硬编码；pricing.html 页面标注 5，见 12.2 口径说明），用户数扩容为【企业版】（代码留 UserXpackService 扩容钩子：GWHowToAddUser/ChangeUser/DeleteUser）
- **用户组管理**：预置系统管理员/系统成员、组织管理员/组织成员、项目管理员/项目成员；三级自定义用户组+菜单权限勾选；恢复默认/重命名/删除
- **组织与项目管理**：组织（编辑/成员/结束；开源版默认仅一个组织，多组织管理为【企业版】）、项目（编辑/成员/进入/结束/**删除——30 天后执行，期间可撤销**）
- **系统参数**：基础配置（站点 URL）、SMTP 邮件、文件大小限制、数据清理（日志保留时长、变更历史保留时长）、显示设置；【企业版】另有界面设置（自定义主题/品牌定制）与认证配置（CAS/OIDC/OAuth2.0/LDAP 单点认证、企业微信/钉钉/飞书扫码登录）
- **模型设置（AI）**：接入 DeepSeek / OpenAI / 智谱 AI 三类供应商，模型的添加/编辑/删除
- **资源池**：Node 型与 K8S 型（kubectl apply 部署 task-runner，Token/命名空间配置）；编辑最大并发数；**社区版限 1 个默认资源池且不可删除**（前端「创建资源池」按钮无 License 时禁用）；【企业版】多资源池 + Controller 统一管理（独立执行节点、节点批量添加、按组织应用、切换/启停/删除，单接口并发突破社区版上限 3）
- **任务中心**：实时任务、定时任务
- **插件管理**：5 类插件（DevOps、API 导入、请求、项目管理、协议）+ 数据库驱动上传（内置 MySQL，可上传 Oracle 等）
- **授权管理**（License 授权体系：license 校验与添加；社区版可见该页面，配到期/试用提醒组件；企业版功能的总开关【企业版】）
- **系统日志**：权限范围内全量操作日志+高级查询

### 9.2 组织级（组织管理员）
- 组织成员（批量添加/改用户组/移除）、组织用户组（自定义+权限）、组织项目（同系统级项目能力）
- **服务集成**：JIRA（Basic Auth/Bearer Token；JIRA 对接插件为【企业版】）、禅道（GET/PATH_INFO 请求型、超级 model 权限）、TAPD 等三方平台对接配置（测试连接；禅道/TAPD 插件为社区版）
- 组织模板（字段/模板/工作流/自定义字段/状态流）、组织任务中心、组织日志
- 开源版默认仅一个组织（多组织为企业版）

### 9.3 个人中心
- 个人信息（头像/姓名/邮箱/手机）、修改密码
- **APIKEY**：Access Key/Secret Key（最多 5 条），用于第三方 API 调用、Jenkins 插件、IDEA 同步插件
- **本地执行**：配置本地 task-runner 地址并检测连通，可设「优先本地执行」
- **三方平台账号**：绑定 JIRA/禅道/TAPD/飞书等账号（缺陷以该账号创建）
- **模型设置**（AI 个人级配置）

## 十、AI 能力（v3.x 重点新增）

- **模型接入**：系统级（系统参数-模型设置）与个人级（个人中心-模型设置）两个入口；支持 DeepSeek、OpenAI、智谱 AI 三类供应商（后端 ai-engine 模块含对应 ChatClient 实现、工具调用引擎 ChatToolEngine、内置 DateTimeTool/JvmTool/IntegrateTool 等工具）

## 十二、企业版（X-Pack）独有功能（专项详解）

> 开源仓库中仅保留接口占位与 License 校验（`io.metersphere.xpack.*`，MybatisConfig 显式扫描 `io.metersphere.xpack.*.mapper`），实现以企业版 jar 运行时注入 Spring 容器。
> License 体系本身在社区版可见：前端有「系统设置-系统-授权管理」页面（`authorizedManagement`）、`validateLicense`/`validateExpiration` 指令、`ms-expire-alert`/`ms-trial-alert` 到期与试用提醒组件；后端 `LicenseController` 提供 license 校验与添加接口。
> 本章为企业版功能汇总视图；各功能模块章节（二~十一）中已同步以【企业版】标注对应能力。

### 12.1 多组织管理
- 创建组织（名称/管理员/描述）、编辑、添加成员、结束（不再出现在切换列表）、删除（连同项目数据一并删除）
- 组织成员查看与移除；项目可挂载到指定组织
- **社区版限 1 个组织**，多组织为企业版能力

### 12.2 用户规模扩容
- **社区版上限 30 个用户**（`USER_TOO_MANY` + `user_open_source_max` 提示；现行代码 SimpleUserService 硬编码 30，与 v3/pricing.html 一致）
- 口径差异：现行 pricing.html 版本对比页标注「最多支持 5 个用户」，与代码及 v3/pricing.html（30）不一致，以实际部署版本为准
- 企业版不限用户数；代码留有 `UserXpackService` 扩容钩子：`GWHowToAddUser`（创建/邀请注册两个重载）、`GWHowToChangeUser`、`GWHowToDeleteUser`

### 12.3 自定义主题 / 品牌定制
- 入口：系统设置-系统-系统参数-界面设置
- 主题色、平台风格（背景色，可跟随主题色）
- 登录页定制：网站 Icon、登录 Logo、背景图、Slogan、网站名称，实时预览
- 平台设置：平台 Logo、平台名称、帮助文档地址
- 恢复默认、保存并应用

### 12.4 单点认证（SSO，8 种方式）
- **LDAP**：地址（389/636）、绑定 DN/密码、用户 OU、用户过滤器（uid/sAMAccountName/cn）、属性映射（username/name/email/phone）、测试连接/测试登录
- **CAS**：服务端地址、登录地址、回调 `/sso/callback/cas/${authId}`、serviceValidate 验证
- **OIDC**：授权端/Token 端/用户信息端/注销会话端 + 回调 `/sso/callback/oidc/${authId}`（文档以 Keycloak 为例）
- **OAuth2.0**：授权端/Token 端/用户信息端/回调 `/sso/callback/oauth2`、属性映射（文档以 GitHub 为例）
- **SAML**（X-Pack 概述页列明）
- **企业微信扫码**：AgentId/Secret/企业 ID、授权回调域、企业可信 IP（前端含 `weComQrCode.vue` 组件）
- **钉钉扫码**：Client ID/AgentId/Client Secret、回调域名、服务器出口 IP 白名单（前端含 `dingTalkQrCode.vue` 组件）
- **飞书扫码**：企业自建应用、网页应用、重定向 URL、H5 可信域名、通讯录权限
- 登录页呈现「更多登录方式」入口

### 12.5 自定义消息模板
- 前置：消息管理已开启通知渠道
- 在消息设置中自定义模板：消息脚本展示内容与变量，字段分用例字段/自定义字段等，点击插入标题/内容
- 支持更新模板、实时预览、保存后预览

### 12.6 多资源池 / 资源池 Controller
- **社区版**：仅 1 个默认资源池（不可删除），单接口任务最大并发：v3/pricing.html 标 3、现行 pricing.html 标 1（代码中未见对应常量，可能由企业版组件或执行侧控制）；前端「创建资源池」按钮在无 License 时禁用（`:disabled="!licenseStore.hasLicense()"`）
- **企业版**：
  - 独立执行节点（前置部署 Task Runner 服务）
  - 资源池 Controller：名称、内网 URL、应用组织（全部/指定）
  - 节点单个/批量添加（IP、Port 默认 8000、最大并发数；参考值 4C8G 支持 1000-2000 并发）
  - 资源池切换（项目/测试计划执行时指定）、编辑、启用/禁用、删除
  - 支持 Node 与 K8S 两种资源池类型（K8S 经 kubectl apply 部署 task-runner）

### 12.7 测试计划组（Test Plan Group）
- 代码实证：`TestPlanXPackFactory.getTestPlanGroupService()` 经 License 校验（status=valid）才返回 `TestPlanGroupService` 实现
- 功能：多计划归入计划组、计划组整体执行与计划组报告
- 口径说明：功能手册与 pricing 对比表将「计划组/测试轮次」列为两版均有，但代码层面计划组由 X-Pack 工厂类启用

### 12.8 缺陷全量同步增强
- `BugService` 中「执行同步全量缺陷(xpack调用)」：全量缺陷同步的执行链路由 xpack 模块增强实现（社区版提供增量同步与基础同步能力）

### 12.9 企业版插件
- **协议插件**（扩展接口测试协议）：pricing 版本对比页列明 WebSocket、MQTT、Thrift、GRPC 四个协议插件为企业版独有（社区版列为"−"，已按页面原始表格核实）；插件文档页另标 TCP、SSH、Redis、MongoDB、AMQP 亦为企业版
- **JIRA 对接插件**：需求关联、缺陷创建及双向同步（插件文档页标注企业版；pricing 页将 JIRA 插件标为两版均有，两处口径不一致；禅道、TAPD 对接插件为社区版）

### 12.10 UI 测试 / 性能测试（企业版方向）
- v3 社区版无独立 UI 测试/性能测试模块（v1/v2 曾有：UI 测试基于 Selenium、性能测试基于 JMeter 分布式压测）
- 代码占位证据：资源池 DTO `loadTest`/`uiTest` 字段、项目菜单管理 `menu.UI_*`/`menu.PERFORMANCE_TEST_*` 配置项（报告保留时间、资源池、脚本审核人）、`PROJECT_APPLICATION_UI`/`PROJECT_APPLICATION_PERFORMANCE_TEST` 权限点、`menu.uiTest`/`menu.loadTest` 多语言文案

### 12.11 其他企业版差异
- ARM64 安装包（仅企业版）
- 原厂企业级技术支持服务，pricing.html 标注为「基础级」档（社区版仅开源社区支持）
- 社区版限制汇总：**1 组织 / 30 用户（pricing.html 标 5）/ 1 资源池节点 / 单接口任务并发（v3 pricing 标 3，pricing.html 标 1）**

## 十三、后端代码模块对照（代码库实证）

| Maven 模块 | 职责 |
|---|---|
| framework/sdk | 基础 SDK、pf4j 插件管理器、JDBC 驱动插件 |

| services/case-management | 功能用例、脑图、评审、AI 生成用例 |
| services/test-plan | 计划、关联用例、执行、报告、计划脑图 |
| services/bug-management | 缺陷、评论、三方同步、回收站 |
