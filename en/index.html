Docs & Help

Three commands to boot the full stack; every design doc ships in the open repository.

Quick start (zero external dependencies)

# Clone & start (web with embedded PostgreSQL + engine + mock)
git clone https://github.com/RabbitAI-Lab/RabbitAITest.git
cd RabbitAITest
pnpm install && pnpm dev

# Quality verification (same as CI)
pnpm test        # Vitest unit tests
pnpm test:api    # JMeter API automation (55 plans)
pnpm test:e2e    # Playwright UI automation (boots the full stack)

# One-command Docker Compose deployment (standard edition)
docker compose -f deploy/docker-compose.yml up -d

Requires Node.js ≥ 20 and pnpm 10. Embedded DB by default; set DATABASE_URL for an external PostgreSQL 16.
